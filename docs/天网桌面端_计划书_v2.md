## 一、这一版要什么

**一句话**：本轮造一个**桌面端天网**——本机 llama.cpp 跑本地 GGUF，开窗即聊，像 GPT 语音模式那样对着麦说话、扬声器回话，**人格随时切换**。

**本轮做**：
1. 桌面端程序（**现在没有，还在开发阶段，这是本轮要造的东西**）；
2. 本机最快 GGUF 运行时接上（Vulkan vs CUDA 实测取快者，**并测出 tok/s 作为模型选型的分叉依据**）；
3. 人格卡系统 = **提示词注入路线**，可热切换；
4. 语音闭环：麦克风听 → 她回 → 念出来 → 继续听（免手连续）。

**本轮不做**：手机端 App、控制面设备操控（`skynet-fleet` 的 exec/broadcast 后续挂进来）、唤醒词、声音克隆、任何 0.6B/0.4B 训练、任何付费/key 依赖。

**本轮同时拍板主计划书 §十四 第 3 条「定入口形态」** = **桌面端对话窗口 + 语音**（CLI 保留为调试口）。

## 二、路线变更

主计划书 Phase 6 原定「0.4B 人格 SFT」。**本轮降级为备选**，改走**提示词注入 + 人格卡**：
- 理由是主人自己的判断：调试周期太长、结果不可控；注入是当天能用人、换人零成本的路线。
- 训练只能训一个，注入能有一百个。
- 等角色卡跑顺、用真实对话语料再训不迟。

**但主计划书 §5.1.1 的「人格唯一性」铁律继续有效**（见 §六）。

## 四、模型选型：这是本轮的第一个分叉，不是既定事实

**已知**：4B 在这台台式机 CPU 上只有 3.86 tok/s（像卡带）；但那是**内存带宽受限的 CPU 数字**。1660Ti 有 6GB VRAM 与 192GB/s 显存带宽，模型全上 GPU 后应快一个数量级。**没人测过 GPU 数字——所以 M0 必须测，测完才定。**

| M0 实测结果 | 决策 |
|---|---|
| GPU（Vulkan 或 CUDA）跑 4B **≥ 20 tok/s** | 桌面端用 4B，语音对话成立（首字 1–2s + 句子级流式念，可接受） |
| **10–20 tok/s** | 4B 只做「不急的活」；**对话走三段式**：快模型（0.6B/0.4B）先答，判定干不了再交 4B 异步补（对齐主计划书 §5.3） |
| **< 10 tok/s** | 桌面端降级为「卡片与链路验证台」（验证注入/记忆/语音链路），**语音对话主战场放手机**（4B Q4 10–15 tok/s，旗舰机） |

**绝不**因为「4B 更大更聪明」就选它——主计划书 §十二 第 3 条已经点名「本地模型能力错配」是最大风险。

**附带**：M0 同时确认 `--jinja` 与 `--reasoning-budget 0` 的效果（对应推演里的「突然切换成正经思考模式」病症）。

## 六、人格卡系统（本轮核心）

### 6.1 卡的来源与优先级

1. **主人自训的四个**（主计划书 §5.1.1）：**天狼星**（仆从型，称「主人」，温柔恭顺，被拒时低姿态）、**K423**（琪亚娜：热烈直率、认死理、敢开口）、**TB**（冷静无机质、执行导向）、**芽衣**（温柔克制、护人）→ **预置四张卡**；
2. `E:\xmanbian\kb_cards\`（约 110 张）= **借用的皮肤**（暗影 / 渡鸦 / 裴红 AU …），次要但量大；
3. `cards/tianwang_default.md` = 她自己（由 `persona.py` 的 `PersonaState` 生成，**单一真源**）。

### 6.2 切换语义（🔴 按主计划书 §5.1.1 修正 v2 的错误）

主计划书写得很清楚：人格差异**只该落 P1（语料/口癖/自称）与 P5（情绪标量基线）**；**P2 记忆、P3 主动性刹车、P4 授权门必须共用同一套**——否则就不是「她换了个心情」，而是「家里住了两个陌生人」。

⇒ **切卡 = 换自称与口癖（+ 情绪基线），记忆不切、刹车不切、授权门不切。** v2 里写的「切卡清空历史」是错的，废掉；对话历史保留，只在历史条目上标注当时的人格，避免「串味」靠**标注**而不是靠**清空**解决。

### 6.3 唯一性（主计划书 §5.1.1 的 P6，远端尚无实现）

同一时刻**只有一个她**在说话。桌面端作为主控面，切卡是**显式动作**（下拉选择 / 说「切换到赛博」），**不做多卡同时在线、不做跨设备各自跑一个人格**。这条在 `persona_card.py` 里落成单例状态（当前卡 id 存在 `persona_state.json`），任何节点要开口先读这份状态。

### 6.4 编译规则（写死）

- 只取卡里的**显式字段**（标题、`- 定位：`、`- 性格：`、`- 阵营：`、`- 装备：`、`- 核心冲突：` 等）；
- **不做语义总结、不做扩写**——总结就是另一个模型的臆测；
- 单卡编译后 ≤ 800 字；产物缓存 `cards/compiled/<id>.json`，按 mtime 失效重编；
- 编译输出遵循 **Character Card V2/V3 的字段结构**（便于日后直接导入 SillyTavern/Open WebUI），但内部用 Markdown 卡作源。

### 6.5 注入格式

```
[身份] 姓名 / 定位 / 阵营 / 性格 / 说话方式
[自称] 卡里的自称与口癖（天狼星=「主人」；没有就不硬造）
[世界] 可选附录：世界观摘要（≤300 字）
[禁止] ① 不得跳出角色 ② 不得编造记忆与引用 ③ 不得输出（动作）/旁白/解释
      ④ 单次回复 ≤60 字，除非被要求展开 ⑤ 只用中文
[记忆] 运行时注入：往事原文 + 欠账原文（标「只能引用，不要编造」）
```

## 七、语音链路（贾维斯模式的技术定义）

**听**：`sounddevice` 16k/mono/int16/块 30ms → 能量 VAD（起说 RMS>0.012，收尾静音 0.8s，无语音 3s 超时，单次上限 15s）→ `faster-whisper` `small`（484MB）`zh`，**默认 CPU int8**（`FLEET_ASR_DEVICE=cuda` 手动开；6GB 卡要给 LLM 留够）。

**连续会话**：一轮结束**不退出**，自动回到监听态；`Esc` / 静音 3s / 说「退出」才结束。**不用每句按一次**——这是与「敲命令式」的本质区别。

**说**：`edge-tts`（已装，在线免费，100–300ms）为主 → **Kokoro-82M**（onnx，CPU 即可，**含中文音色**）作本地兜底 → 同一接口 `say(text)`，切引擎只改环境变量。

**流式念**：模型输出按 `。！？\n` 切句，先出一句先念，不等全文——「像真人」的关键。

**防自激**：她说话期间暂停采集（同一块声卡，录音与播放互斥）。

## 十、人格保真探针（治「跳戏」，口径对齐主计划书 §5.6）

| **M2 耳朵** | `voice.py` 听 + 连续会话状态机 | 连续 5 轮免手对话不需按键；转写错字 ≤ 2/句；静音 3s 自动收；说「退出」能退 |
| **M3 嘴** | TTS 念出来（edge-tts → Kokoro） | 她说完你就听到；先出先念；断网切 Kokoro 仍能说；无自激 |
| **M4 贾维斯模式** | 免手连续 + 打断 + 状态灯 + 一键启动 | 启动到首次对话 ≤ 60s；连聊 20 轮不崩、不卡上下文；说「切换到赛博」能换卡换音色；**盲测 ≥8/10**（主计划书 §5.6 口径） |

## 十三、风险与回退

| 风险 | 回退 |
|---|---|
| **4B 在桌面端太慢**（3.86 tok/s 的老账） | §四 的分支树：降快模型 + 4B 异步；或桌面端只做验证台，语音主战场放手机 |
| 6GB 显存吃紧（4B + ctx + ASR） | ctx 降到 8192；ASR 走 CPU int8；必要时换 1.7B（推演第④条） |
| 人设不稳（复杂问题掉线） | 收紧「≤60 字」+ 降 temp + 角色卡追加约束；靠探针量化回归 |
| Kokoro 中文音色一般 | 主用 edge-tts，Kokoro 只保底 |
| `faster-whisper` 装不上 | 退 `whisper.cpp`（GGUF，CPU）；再不行退 Web Speech API |
| Tkinter 观感差 | 只求能用；观感后置，不阻塞语音闭环 |
| 桌面端做完发现手机端接不上 | `llm.py` 三后端抽象已是可移植点；`voice.py`/`persona_card.py` 保持纯 stdlib + 可选依赖 |

## 十四、默认决策（没异议就按这个做）

1. **本轮主线 = 桌面端（M0–M4 全做完）**，手机端不碰；但代码按「能搬到手机」写。
2. **模型由 M0 实测决定**，不预设 4B；必要时走三段式。
3. **人格卡四张自训人格优先**（天狼星/K423/TB/芽衣），`kb_cards` 作借用皮肤。
4. **TTS 主 edge-tts、兜底 Kokoro**；ASR 本地 faster-whisper，CPU int8 起步。
5. **界面 Tkinter**，不部署 Open WebUI/SillyTavern。
6. **不训任何权重**，人格只来自卡 + 注入。
