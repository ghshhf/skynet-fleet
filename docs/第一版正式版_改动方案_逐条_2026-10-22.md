现有只有 `--no-window` / `--smoke` / `--port` / `--theme`。新增：


**为什么默认不开**：现在的默认是「随机端口 + 只绑本机」，这是安全默认。`--link`/`--lan` 是显式选择，不改变双击就用的行为。

## A2 · 第 98 行：按参数决定 host 与 port

```python

port = args.link_port if args.link else args.port
host = "0.0.0.0" if args.lan else "127.0.0.1"
```

**`--lan` 的硬闸（关键）**：`FLEET_GUI_TOKEN` 没设就 **拒绝启动**，报明确原因后退出。
理由：随机 token 只在内存里，手机根本拿不到；这时把服务开到 `0.0.0.0` 等于「局域网里谁都能驱动这台电脑的桌面」。宁可起不来，也不能悄悄开。

```python
if args.lan and not (os.environ.get("FLEET_GUI_TOKEN") or "").strip():
    raise SystemExit(
        "局域网模式必须固定令牌，否则等于把桌面开放给整个局域网。\n"
        "先设：set FLEET_GUI_TOKEN=<一串足够长的随机字符>（PowerShell: $env:FLEET_GUI_TOKEN=\"...\"）")
```

## B · 新增 `fleet/gui/link.py`（约 90 行）

三个函数：

```python
def devices():                  # adb devices → [serial]，跳过 offline
def ensure_reverse(port):       # 对每台设备 adb -s <s> reverse tcp:port tcp:port
                                #   然后 adb -s <s> reverse --list 读回复核
def report(port, token, r):     # 打印上面那四行
```

🔴 **必须读回复核**，不许「命令返回 0 就算成功」。
这条是 P1 踩过的坑：`SCROLL` 返回 OK 但界面没动（`ACTION_SCROLL_FORWARD` 的返回值不代表真的滚了）。`adb reverse` 同理会静默失败（某些 ROM），所以要用 `reverse --list` 读回真实列表。

失败时的报错（不吞）：
- 无设备 → `没找到在线设备：先确认 USB 连接或无线调试开着（adb devices）`
- reverse 失败 → 带 adb 原始输出
- 读回为空 → `命令报成功但 reverse --list 里没有这条，隧道没真建起来`
