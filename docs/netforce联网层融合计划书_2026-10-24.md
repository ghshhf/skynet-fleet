### P0 接活 —— 路径自动发现

**目标**：换盘、换机、换 clone 位置都不再需要手动指路径；唯一约定是「两个项目放同一个父目录」。

**判据（marker）而非拍死路径**：

```python
# fleet/netrunner.py
_NETFORCE_MARKERS = ("resource_finder.py", "skynet/__init__.py")
_PAPERS_MARKERS = ("tools/ai_frontier_crawl.py",)

def _discover_home(name, markers, extra_dirs):
    """环境变量优先（显式逃生口）；否则按候选目录逐个验 marker。
    返回第一个命中的；全不命中返回第一个候选（报错时给人看的路径）。"""
```

候选顺序（**全部是推出来的，不含私人盘符**）：

1. 环境变量 `NETFORCE_HOME` / `PAPERS_HOME`
2. `<天网仓库父目录>/netforce` ← 主力，当前布局即命中
3. `<天网仓库>/vendor/netforce`（想内嵌放置时的落点）
4. `<天网仓库父目录>/code/netforce`
5. 历史默认 `D:\code\netforce`（老机器兼容，找不到自然跳过）
6. `~/code/netforce`

**同时改**：

- `NETFORCE_DATA` 默认从 `D:\work\_netforce_data` 改为同级 `_netforce_data`（netforce 侧 `CORPUS_DIR.mkdir(parents=True, exist_ok=True)`，会自动建）

### P1 统一子进程出口（隐藏窗口）

**目标**：全仓 20+ 处裸 `subprocess.run` 收敛到 `fleet/_winproc.py` 一个出口，行为与 `net.py::_hidden_startupinfo()` 对齐：`SW_HIDE` + `CREATE_NO_WINDOW` + `stdin=DEVNULL`，**每次新建 STARTUPINFO**（复用会被子进程继承污染）。

**改动顺序**（低风险优先）：

1. 新增 `fleet/_winproc.py`：`run(argv, **kw)` / `popen(argv, **kw)`，非 Windows 自动降级为裸调
2. 逐个文件替换：`android_device.py` / `discovery.py`(2) / `fleet/acquire.py` / `fleet/gui/link.py` / `fleet/gui/voice.py` / `fleet/kinds/adb_wifi.py`(2) / `fleet/kinds/host.py` / `fleet/kinds/pc_control.py`(走既有 `_subprocess_run` 出口，改它一处即可) / `fleet/kinds/render.py` / `fleet/kinds/render_html.py` / `fleet/kinds/windows_pc.py` / `fleet/mcp/client.py` / `netrunner.py`（已有，改走统一出口）
3. `adb_wifi.py:161` 注释已承诺「门禁可换掉 `_subprocess_run`」——保持这个契约，只是实现换新出口

**验收**：GUI 跑一遍 `nodes` / `ui` / 语音，视觉上不闪黑框；`run_selftests.py` 47 项仍全绿。

**边界**：`render_html.py` 要起 node 渲染进程、`mcp/client.py` 要起 MCP server——**它们可能真的需要窗口**？先查：两者都是捕获 stdout 的后台进程，一律隐藏。若后续发现例外，单独加 `show=True` 参数，不搞全局开关。

### P2 证据分级（authority 四级）

**目标**：把「读到的」和「猜的」分开，成为全编队的数据结构，不再是注释里的口头铁律。

**四级（照 netforce `reverse.py:170` 的形状，不搬代码）**：

| 级 | 含义 | 天网侧的对应物 |
|---|---|---|
| `shipped-artifact` | 实物读到 | 页面真出现的字符串 / 设备自报的 mDNS 名字 |
| `controlled-replay` | 自己跑一遍看到 | `probe()` L4 解析校验通过 / 自测复现 |
| `historical-reference` | 外部已知 | 历史账本里的记录、规则库旧版本 |
| `analyst-inference` | 我们猜的 | 端口投票推断的设备类别、OUI 查不到的厂商 |

**落点**：

- 新增 `fleet/authority.py`：`AUTHORITY` 常量 + `mk_evidence(facet, claim, value, authority, target)`，**id 对 (facet, claim, value, authority) 取 sha256 前 16 位 ⇒ 同一结论同一 id**（这是 reverse.py 最该抄的形状）
- `netforce_skynet.search/fetch/probe/structure` 的返回值加 `authority` + `evidence` 字段
- `discovery.py` 的设备识别结果补 authority：`设备自报 = shipped-artifact`，`端口组合投票 = analyst-inference`（README 里 ④⑤ 两个真实误判正是缺这个标注）
- `recall.py` 引用往事时带 authority，模板句区分「原文」与「润色」

**验收**：门禁新增 `evals/t17_authority.py`：① 同一结论两次生成 id 相同；② 每条 web 结果都有 authority 且取值合法；③ discovery 的端口投票结果标 analyst-inference。

### P3 供给自增长（evolve 接进来）

**目标**：解决 `web.discover` 的重复率 71.8% 撞顶——查询空间不再等于人手写的关键词数量。

**机制（netforce `evolve.py` 的两个能力）**：

1. **外链矿 `harvest_outlinks()`**：已收录的每个站都是矿点，首页外链即候选；资源站互相引用是同质网络，信噪比高于搜索引擎
2. **关键词自举 `bootstrap_keywords()`**：从已收录站 title 抽高频短语造新查询（中文走「分类名 × 后缀模板」绕开无分词器；英文走 n-gram）

**落点**：`fleet/webseed.py` 包成两个 `web.*` 能力 + 一个 REPL 命令：

- `web.seed {limit}`：跑一轮外链矿，产出候选 URL 清单（走子进程，带分钟级限时）
- `web.queries`：从已收录 title 造新查询词（只读，不动网络）
- 产出去 `NETFORCE_DATA`，与 `resources.json` 分开，不污染主索引

**验收**：门禁 `evals/t18_webseed.py` 用假收录账本验证「产出是已收录站的超集之外的新 URL」；真机手动跑一轮，看重复率是否低于上一轮。

### P4 取文增强（route / dns）

**目标**：`web.fetch` 面对短链跳转和 DNS 污染不再静默失败。

- `web.origin`：跳转链穿透（`route.py`），返回最终 URL + 每一跳
- `web.dns`：DoH 解析 + 污染判据（`dns.py`），判据喂给 `curl --resolve`
- 这两个都挂在 `netforce_skynet.py` 桥接下，不新增外部依赖

**验收**：门禁 `evals/t19_route_dns.py` 用本地假跳转链验证；真机对一条已知短链跑 `web.origin`。

## 五、不许违背的纪律

1. **不 vendoring**：netforce 代码一个字不复制进天网，只 import + 适配。`netforce_skynet.py` 头部已写理由（仓库体积 + 人肉同步两份会静默用旧版）。
2. **不改 netforce 仓库一个字**：路径全走环境变量与候选推断。
3. **License**：netforce 是 Non-Commercial，天网是 MIT —— **「只 import 不复制」恰好绕开 license 污染**，这是纪律 1 的法律侧理由，写在这里免得将来有人为了「省一次子进程」把它搬进来。
4. **找不到就如实说没装**：不许静默降级、不许用假数据填。`web.papers` 现在就是正确示范（train_15b 已迁走，能力如实不可用）。
5. **后台不弹窗**：P1 之后全仓唯一出口，任何新增 `subprocess` 调用走 `_winproc`。
6. **前台执行**：这些改动在对话里跑，不起后台进程。
