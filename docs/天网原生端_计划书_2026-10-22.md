## 一、目标

不再往浏览器标签里塞页面。两头都做成**双击/点图标即开的本地程序**：

| 端 | 交付物 | 判据 |
|---|---|---|
| 电脑原生端 | 一个 `.exe`，双击出窗口，无终端、无地址栏、无浏览器 | 双击到首次能说话 ≤60s，全程零浏览器 |
| 手机原生端 | 一个 `.apk`，桌面有图标，点开是 App | 桌面图标点开即可录音对话，全程零浏览器 |

**不做的**：不重画界面。已有的光球/字幕/三键形态（`desktop.py`）和手机截图里那套
（`web.py`）就是既定设计，原生端照它复刻，不引入新视觉语言。

## 三、电脑原生端 · 方案（工作量小，先做）

### 3.1 做什么

不新写界面。把**已有的 `desktop.py`** 变成双击即开的 `.exe`：

1. **无窗启动器**（照搬 `scripts/start_llm_hidden.py` 已验证的三件套）
   - `STARTUPINFO + STARTF_USESHOWWINDOW + SW_HIDE`
   - `creationflags=CREATE_NO_WINDOW`
   - `stdin/stdout/stderr` 全 `DEVNULL`
2. **PyInstaller 打包**
   - `--noconsole --onedir`（**不是 onefile**：语音依赖 + 模型加载，onefile 每次解压几十秒）
   - 排除用不上的大件（`tkinter.test`、`matplotlib`、`scipy` 若被误拉）
   - `--name 天网`，图标可选
3. **模型不进包**：faster-whisper / GGUF 走 `E:` 外挂，沿用已落地的多候选探测
4. **首次启动自检**：打包产物自带 `--smoke`（起窗口 3s 即退 + 探语音/模型路径），
   失败必须在窗口里说清缺什么，**不许双击没反应**

### 3.2 已知坑（先写在这里，省得到时候瞎试）

| 坑 | 对策 |
|---|---|
| PyInstaller 后 `__file__` 指向临时目录 | 路径解析改 `sys._MEIPASS` 感知；数据文件用 `--add-data` 或走绝对盘位探测 |
| onnxruntime / ctranslate2 的动态库漏打 | `--collect-all onnxruntime`、`--collect-binaries ctranslate2`，逐个冒烟 |
| 中文名 exe + 无窗输出丢失 | 日志一律落 `%TEMP%\tianwang_desktop.log`，不靠 stdout |
| 双击闪退看不见原因 | 启动器捕获异常写日志 + 弹 `MessageBox`（tkinter 自带，不引依赖） |

### 3.3 验收

1. 拷到干净目录（不依赖仓库路径）双击 ⇒ 出光球窗口，任务栏无终端黑窗
2. 说一句 ⇒ 有字幕 ⇒ 出声（kokoro）
3. 切卡 ⇒ 自称与音色都变
4. 关窗进程退干净（任务管理器无残留）

**做不到第 1 条就不算原生端。**

## 四、手机原生端 · 方案（本轮主体）

### 4.1 两条路，请拍板

| | A · 纯原生 View（推荐） | B · WebView 壳 |
|---|---|---|
| 界面 | 手写 XML + Java，光球用 Canvas 画 | 复用现有 `INDEX_HTML` |
| 录音 | `AudioRecord` 16k mono PCM→WAV（**不经浏览器，无安全上下文限制**） | 走 WebView 的 getUserMedia |
| 依赖 | 零第三方库（与 `fleet-bridge` 一致） | 零第三方库 |
| 体积 | 估 60–90KB | 估 40KB |
| 工作量 | 大（约 900–1200 行 Java/XML） | 小（约 250 行 Java） |
| 真"原生" | ✅ | ❌ 本质还是网页 |
| 风险 | 手写布局细节多，需真机反复截图调 | 几乎无 |

**我的建议：A。** 理由：主人要的是"原生端"，且 B 的录音仍受 WebView 权限/安全上下文
牵制，等于把刚绕开的坑又踩回去。A 的录音是 `AudioRecord`，物理上不可能被"非安全上下文"拦。

> 若主人选 B，本计划书 Phase 2 整体替换为「WebView 壳 + 原生录音桥」，其余不变。

### 8.1 「合成一个原生」怎么合

两个技术栈**物理上塞不进同一个窗口**：

- `desktop.py` = Tkinter（767 行，光球/字幕/三键）
- `ui/` + `fleet/gui` = Web（pywebview，app.js 65KB，六视图三栏）

要让它们在一个窗口里，必须选一个底座，另一个重画。选 **Web 底座**，理由是实跑核验过的：

| 事实 | 证据 |
|---|---|
| 壳能开窗 | `python -m fleet.gui.app` 实测出窗口「设备编队」，pid 12908 |
| 壳能冒烟 | `--smoke` 通过：12 设备 / 87 能力 / 后端 pollinations |
| **后端本来就是人格对话** | `server.py::_post_chat` 走 SSE 真流式；`PersonaBridge` 直接读 `persona_card.py` 的 `build_system`/`match_world_book` |
| **前端本来就预埋了语音位** | `ui/index.html` 有 `#voiceBar`，注释原文「W1 只是 UI 占位，语音在 W4 接」 |
| 六视图已存在 | `chat`/`crew`/`assets`/`todo`/`lib`/`more`，侧栏 `data-view` 切换 |

**代价（必须认）**：`desktop.py` 那 767 行光球状态机要**用 Canvas 重画成 Web**。
但那本来就是几何图形（同心圆 + 呼吸/波纹/脉冲），Canvas 比 Tkinter 更好画也更好看，
不需要像素级搬运——搬的是**状态机语义**（IDLE 慢呼吸 → LISTEN 波纹 → THINK 转圈 →
SPEAK 脉冲），不是代码。

**处置**：`desktop.py` 保留在仓库不删（它仍是可跑的 Tkinter 版，作对照与回退），
但**不再打包、不再作为交付物**。交付物只有一个：`天网.exe`。

### 8.2 一个 exe 的双视图

```
天网.exe（pywebview 一个窗口）
├── 侧栏「◉ 语音对话」  → view-voice：光球 + 字幕 + 麦克风/免手   ← 本轮新增
├── 侧栏「◉ 新建任务」  → view-chat ：三栏对话（已有，SSE）
├── 侧栏「◐ 助理」      → view-crew ：角色编队（已有）
├── 侧栏「⌘ 专家技能」  → view-assets（已有）

```

后端只需补两个路由，其余全复用：

| 路由 | 干什么 | 内部调谁 |
|---|---|---|
| `POST /api/voice/recognize` | 收 wav → 文字 | 根目录 `voice.transcribe()`（不是 `fleet/gui/voice.py`，那是命令式那套） |
| `POST /api/voice/say` | 文字 → wav（卡片音色） | 根目录 `voice.say_for_card()` |

**硬约束**：两个 exe 的旧方案作废后，`desktop.py` 与 `web.py` 的后端接口**不回改**，
只在 `server.py` 里新增两个转发路由 —— 不动已有 42KB 的任何一行逻辑。

### 9.2 过程中被门禁抓到的真问题

- `t7_front_smoke` 报 `requestAnimationFrame is not defined`：门禁的模拟 DOM 里没有 rAF，
  我新加的 `orbLoop()` 直接抛 ⇒ **门禁抓到的真问题，不是误报**。
  修法：`typeof requestAnimationFrame === "function"` 才递归，`orbDraw()` 用 try 包住。
  这条印证纪律：**新代码必须跑一遍门禁，别假设浏览器里没事就没事**。

### 9.3 打包链路的既有资产（省了一次重造）

`tools/build_gui.py` + `tools/fleet_runtime_hook.py` + `PACKAGING.md` **早就存在**，
配方已经钉死（`--paths` / `--collect-submodules fleet` / `--add-data ui:ui` / runtime hook）。
本轮只补了三处缺口：

1. **hidden-import** 补 `voice`（仓库根那个）、`faster_whisper`、`ctranslate2`、`edge_tts`
   —— 否则冻扁包里 `/api/voice/*` 一调就 `ModuleNotFoundError`；
2. **`--add-data cards`** —— 原先只打 `ui/`，卡库不在包里；
3. **runtime hook 加「卡片播种」** —— hook 原本把 `FLEET_CARD_DIR` 重定向到
   `%APPDATA%/fleet/cards`（可写），但那里首次是**空的** ⇒ 打开就是空卡库、没音色。
   现在首次启动从包内 `cards/` 补缺拷贝，不覆盖用户改过的卡。

### 9.4 一个必须如实报的取舍：冻扁包里没有 kokoro

`build_gui.py` 的 `EXCLUDES` 里有 `torch`，这是架构铁律（fleet 解释器绝不 import torch，
Polaris 的 STT 是子进程）。而 **kokoro 依赖 torch**。后果：

- `voice.say()` 的顺序是 kokoro → edge → none；
