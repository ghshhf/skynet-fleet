## 一、为什么现在做语音（问题定位）

三件事叠在一起，语音成了当前唯一的堵点：

1. **全仓库只有一处真的调模型**——`commander.py:826`（`_her_compose`，她主动开口）。**「用户说话 → 她回」这条路至今不存在**，`persona` 的主动性再完整也只能单向广播。语音是把这条路打通最短的一刀，且不依赖 0.6B 权重（她可以先借用任何已接的模型说话）。
2. **计划书自己把语音权重排在第一位**（`docs/个人设备编队与本地她_计划书.md` 第 97、401 行），但入口形态一直挂着「待定」，所以每次都被推迟。
3. **只有一台机器有耳朵和嘴**。实测本机：麦克风阵列 (Realtek) `OK`、扬声器 (Realtek) `OK`、蓝牙耳机 J08（含免提麦）。另一台没有语音，因此语音相关只能在这台开发——**但设计上不能做成「本机专属」**，否则另一台永远残废。

## 二、目标与非目标

**目标（本轮交付）**

- V1：能让「她」出声。`her_say --speak` 与 `voice --say` 都能听到中文女声，断网自动退离线语音。
- V2：能听、能回。对麦说一句话 → 本地转写 → 带上记忆与欠账的上下文 → 她回 → 出声 → 双方各落一条流水。

**非目标（写死，本轮不碰）**

- 不做唤醒词（「你好，小爱」那类常驻热词侦听），不做随时打断（流式 barge-in）。
- 不做声纹识别、不做情感声学分析。
- 不做 V3 跨设备语音路由（节点能力上报留接口，不实现路由）。
- 不动 0.6B 权重、不训模型、不改数据规格。
- 不碰浏览器。

## 三、设计判断：语音是编队资源，不是本机功能

按四原则第 1、4 条，语音必须和算力池同构：**能力上报 + 按谁能干路由**。

```
有麦的机器（本机）     = 耳朵 + 嘴
没麦的机器（另一台）    = 手 + 脑，talk 自动退纯文字
```

本轮只做「本机自己听自己说」，但 `voice.caps()` 一开始就按能力字典返回，后面接节点上报时不用改形状。这样「另一台没语音」不再是缺陷，而是路由的应然结果。

## 五、接口契约（照这个签名写，不临场改）

### 5.1 `voice.py`

```python
caps() -> dict
    # {"asr": bool, "tts": "edge"|"sapi"|None, "asr_engine": "faster-whisper"|None,
    #  "devices": {...}, "why": {"asr": "...", "tts": "..."}}   —— 缺什么都要给出原因

say(text, voice=None, rate=0, play=True) -> (backend, wav_path|None)
    # 顺序：edge-tts（在线）→ pyttsx3/SAPI（离线）→ ("none", None) 只打印不抛
    # edge 路径：mp3 → ffmpeg → wav(16k/mono) → winsound.PlaySound；ffmpeg 缺失则退 SAPI

record(max_s=15, samplerate=16000, silence_end=0.8, no_speech_timeout=3.0) -> (wav_path|None, info)
    # 能量 VAD：说过话后静音 0.8s 收尾；3s 无声返回 None（不卡死）；总长上限 15s

transcribe(wav_path, model="small", language="zh", device="auto") -> (text, meta)
    # faster-whisper 懒加载单例；device="auto" 先试 cuda，AttributeError/CuDNN 缺失自动退 cpu int8

listen(**kw) -> (text, wav_path, info)          # record + transcribe
probe_playback() -> bool                        # 有没有能出声的设备
```

### 5.2 `dialogue.py`

```python
build_context(journal, ctx, st, now=None, turns=6, recall_k=3, followup_k=2) -> dict
    # {"system": str, "history": [{"role","content"}...], "evidence": {"recall":[...], "followups":[...]},
    #  "degraded": [...]}
    # 历史来源：journal.recent(hours=24, kinds=("user","her"), limit=turns*2)，时间正序
    # system 组成：身份锚(name/traits/catchphrase) + 禁止项(不旁白/不括号动作/不解释/不超 60 字)
    #              + 若有往事 →「你可能记得（只能引用，不要编造，不许说“我们聊过”这种空话）」附原文
    #              + 若有欠账 →「还没做完的事（可以提，不许承诺做不到的）」

reply(text, journal=None, ctx=None, st=None, speak=False, use_recall=True) -> dict
    # {"say","backend","evidence","degraded","ms"}
    # 关键：被动应答**不过** ProactiveEngine.allow()——频控/静默是给「主动打扰」的刹车，
    #       用它拦用户的提问＝她不回话。这是本轮最容易写错的一处，自测要专门覆盖。
    # 落盘：journal.log("user","user",text) + journal.log("her","her",say)
    # 往事命中后调 recall.mark_recalled 记账（避免 3 天内重复提）

talk_once(text=None, speak=True, **kw) -> dict
    # text 为空 → voice.listen() 取话；拿到话 → reply() → 可选 voice.say()
```

## 六、降级矩阵（必须逐格实现，不许「先只做能跑的那格」）

| 情形 | 听 | 说 | 用户看到的结果 |
|---|---|---|---|
| 齐全 | 本地 whisper | edge-tts | 完整对话 |
| 无麦 | 报「这台没有耳朵」并退文字输入 | 正常 | `talk 文字` 仍能对话，她仍会念 |
| 无网 | 正常 | SAPI / pyttsx3 | 音色变差，仍能说 |
| 无 GPU | whisper CPU int8（慢 3–5 倍） | 不变 | 能忍，不报错 |
| 依赖全缺 | `talk` 不可用，明确说缺哪个包 | 只 print | 等价于现有 REPL，不崩 |

## 七、参数（一次定死，写在文件顶部常量，可被环境变量覆盖）

| 项 | 值 | 理由 |
|---|---|---|
| 采集 | 16000 Hz / 单声道 / int16 / block 30ms | whisper 原生 16k，省一次重采样 |
| VAD 起说阈值 | RMS > 0.012 | 安静房间实测可用，噪声大时用 `FLEET_VAD_RMS` 调 |
| 收尾静音 | 0.8s | 短于 0.5s 会把句中停顿切断 |
| 无语音超时 | 3.0s | 防 REPL 卡死 |
| 单次上限 | 15s | 超了强制结束，避免长篇独白占麦 |
| whisper | `small` / `zh` / `beam_size=1` / `vad_filter=True` | 中文够用；`medium` 在 6GB 卡上会挤掉 4B |
| 算力 | 默认 `cpu int8`，`FLEET_ASR_DEVICE=cuda` 手动开 | 1660Ti 6GB 与本地 4B 争显存，先稳后快 |
| TTS 音色 | `zh-CN-XiaoxiaoNeural`（`FLEET_TTS_VOICE` 可换） | 温和，符合她的人设 |
| TTS 语速 | `+0%`（`FLEET_TTS_RATE`） | 先中性，听感再调 |
| 历史轮数 | 6 轮（12 条） | 够接话头，不撑爆 4K 上下文 |
| 往事 / 欠账 | k=3 / k=2 | 与 `persona` 主动起话头的权重一致 |
| 录音落点 | `G:/_tmp/fleet_voice/`，用完即删 | 录音是隐私面，默认不留 |

## 八、代价与数据来源

**装三个包（全部落 G 盘 venv/系统 site-packages，走代理 `http://127.0.0.1:3067`）**

| 包 | 用途 | 体积 |
|---|---|---|

**已就绪**：`edge-tts` ✓、`numpy` ✓、`ffmpeg` ✓（`G:/dev/ffmpeg/bin`，需补进 PATH 或设 `FLEET_FFMPEG`）。
**合计新增磁盘** ≈ 610 MB，全部在 G 盘，E 盘仓库零增量。

## 十、自测怎么做到离线（不进真麦、不联外网）

- **VAD**：用 numpy 合成「静音 0.5s + 正弦 1s + 静音 1.2s」的 wav，断言切出的话段长度落在 0.9–1.2s。
- **转写**：喂 1s 静音 wav，断言返回空串且不抛（证明空输入不炸）；不依赖模型是否下载，模型不存在时跳过并标 `skipped`。
- **出声**：`play=False`，只断言「生成了非空 wav 且 backend 正确」；不真的播，避免自测时突然出声。
- **对话**：假 journal（临时 sqlite）+ 假 ctx + 打桩 `llm.complete`，断言 ①历史顺序正序 ②往事原文进了 system ③system 含「不要编造」约束 ④`user`/`her` 各落一条 ⑤placeholder 时 `degraded` 有标记 ⑥**不经过 `eng.allow()`**。

## 十一、隐私与安全边界

1. 录音默认不落盘留存（`G:/_tmp/fleet_voice/`，转写后即删；`FLEET_VOICE_KEEP=1` 才保留 24h）。
2. 录音与转写文本只进本地流水（已打码），**不上传任何在线 ASR**——`edge-tts` 只发送要念的文本，不发送音频。
3. 她说话期间暂停采集，避免把她自己的声音录成下一轮输入（自激）。
4. 不在群/频道/真人侧发声；出声只对本机声卡。

## 十三、风险与回退

| 风险 | 概率 | 回退 |
|---|---|---|
| `edge-tts` 接口变更/被墙 | 中 | `FLEET_TTS_EDGE=0` 强制 SAPI；音质降但可用 |
| `faster-whisper` 装不上（缺 VC++ / AVX） | 中 | 备选 `vosk` 中文小模型（42 MB，准度略低）；再不行退文字输入 |
| `winsound` 只吃 wav | 已定 | 全走 ffmpeg 转码；`FLEET_FFMPEG` 可指绝对路径 |
| 1660Ti 显存不够（ASR + 4B 同跑） | 高 | 默认 CPU int8，ASR 不吃显存 |
| 她答得不像她（placeholder 或 4B 直出） | 高 | 本轮只验链路；人格归 Phase A 权重，`system` 里先放 30 字身份锚 |
