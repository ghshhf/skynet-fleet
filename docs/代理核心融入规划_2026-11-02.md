# 天网代理核心融入规划

> 目标：未来把订阅链接直接递给天网，天网自己解析、接管流量、分流、加速，不再依赖 Karing / Clash / v2rayN 等第三方客户端。
> 状态：规划稿（2026-11-02），随实施推进更新。进度以本文件与 README 为准。

## 结论（一句话）

天网要替代 Karing 这类客户端，**缺的不是「管理面」，是「数据面」**——一个能真正接管整机流量、跑通全协议的转发核心。管理面（订阅解析 / 节点归一 / 测速 / 规则分流 / 逆向深解）已经就绪，数据格式已照抄 sing-box。最优路径是学 Karing 的架构：**控制面天网自研，数据面借 sing-box 核心**，不自己重写转发内核。

## 天网现状盘点（哪些已有）

- `fleet/proxymgr.py`：订阅解析(Clash YAML / V2ray link / sing-box JSON)、节点归一、测速选优、规则路由、逆向深解。**管理面已就绪**，数据格式照抄 sing-box outbound / rule-set。
- `fleet/netaccel.py`：gitport 克制型转发（只救 GitHub/arXiv 这类「换 IP 即通」的站），PAC 路由 + 系统代理开关 + 热点网关。明确「不是通用翻墙」。
- `fleet/tunnel.py` + `nat.py` + `relay_pair.py` + `rendezvous.py` + `skynet_relay.py`：点对点 NAT 打洞 / 中继隧道（设备互联用，不是代理翻墙数据面）。
- `fleet/reverse.py` / `proto_reverse.py` / `bit_reverse.py`：逆向深解（天网独有，可做未知协议兜底）。

## 差距（缺什么）

1. **数据面**：无通用流量转发核心（TUN 虚拟网卡 + 全协议出站 + DNS 分流防泄漏）。这是最大缺口。
2. **协议落地**：`proxymgr` 能解析 11 种协议，但没有核心能真正把流量按这些协议转发出去。
3. **策略组**：只有一次性测速选优，无「持续健康检测 + 失败自动切换」。
4. **规则引擎**：无逻辑规则(AND/OR/NOT)、GeoSite 按需加载、进程名匹配。
5. **DNS**：无 FakeIP / DoH / DoT / sniffer 嗅探防泄漏。

## 融入路线图（分阶段）

### 阶段 0（已完成）
管理面就绪：订阅解析、节点归一、测速、规则分流、逆向深解，数据格式照抄 sing-box。

### 阶段 1（✅ 已完成 2026-11-02）：接数据面核心，最小闭环
- 引入 sing-box 单二进制，天网生成 JSON 配置并拉起核心进程。
- 复用 `proxymgr` 的节点/规则数据 → 生成 sing-box 配置（outbound + route + dns）。
- 打通「订阅 → 解析 → 生成配置 → 拉起核心 → 系统代理/TUN 接管流量」。
- 验收：把一条 Clash/V2ray 订阅丢给天网，天网能让你直接翻墙访问墙外站点，不用开 Karing。
- **成果**：`fleet/proxycore.py` + `fleet/kinds/proxy_core.py` 落地，实测 Google/YouTube 200 翻墙成功。

### 阶段 2：策略组健康检测 + 自动切换（抄 mihomo）
- urltest/fallback：定时测节点，失败自动切下一跳（天网已有 `probe_node/probe_all`，扩展成持续检测）。
- 多订阅源合并、按延迟分组选优。

### 阶段 3：DNS 防泄漏 + 规则集升级（抄 sing-box / mihomo）
- DoH / DoT / FakeIP + sniffer 嗅探。
- 逻辑规则 AND/OR/NOT、GeoSite 按需加载。
- 复用已 clone 的 `karing-ruleset`（586 域名 / 7465 CIDR）。

### 阶段 4：协议增强（抄 Xray / hysteria2）
- VLESS-Reality（抗封锁）、Hysteria2（双边加速）、TUIC、ShadowTLS、WireGuard。
- 这些 sing-box 核心本身支持，主要是配置面补齐。

### 阶段 5（可选）：逆向深解 + 自研数据面
- 天网独有的 `proto_reverse` 对未知/新协议做深解。
- 长期可用 `tunnel.py` 隧道能力做自己的数据面（重活，先借核跑通再说）。

## 关键技术决策

- **数据面选 sing-box**：协议最全、Karing 同款、单二进制零依赖、控制面可完全天网自研（JSON 配置）。
- **控制面天网自研**：`proxymgr` 已就绪，喂配置给核心即可。
- **不自己重写转发内核**：避免重复造轮子，学 Karing「控制面自研 + 核心借力」。
- **克制与通用并存**：保留 gitport 的克制型（只救 GitHub/arXiv），新增 sing-box 通用型（用户显式订阅时才开）。
