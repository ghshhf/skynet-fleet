## 三、手机上必须先破的四个硬约束

这四条不解决，手机端写了也跑不通。全部已实测/查证：

### 3.1 麦克风权限：`http://<局域网IP>` 直接被拒
浏览器只在**安全上下文**（https / localhost / 127.0.0.1）下给 `getUserMedia`。
局域网 IP 明文 http 一定失败。

**解法（两条并存）**：
- **开发与验收**：`adb reverse tcp:8765 tcp:8765` ⇒ 手机访问 `http://localhost:8765`，天然是安全上下文。
- **拔线可用**：`web.py` 支持 `--tls` 自签证书，手机首次手动信任一次。

### 3.2 Android Chrome 没有 Web Speech API
`window.SpeechRecognition` / `webkitSpeechRecognition` 在 Android 上是 `undefined`，
且 Web Speech 依赖厂商联网服务（国内基本不可用）。
⇒ **手机侧唯一可走的是「本地录音 → 上传 → 桌面 whisper 识别」**。

### 3.3 `whisper.transcribe()` 只吃 wav
它内部按 RIFF 解析时长与静音（`_wav_duration` / `_wav_is_silent`），
`MediaRecorder` 出的 webm/opus 直接喂会得到 0 秒。

**解法**：前端用 `AudioContext` 录 PCM，降采样 16k，手写 44 字节 WAV 头。
后端 `/api/voice/recognize` 同时加 ffmpeg 兜底（收到非 RIFF 就转一次），双保险。

### 3.4 手机系统 TTS 音色不是卡片的
现在网页用 `speechSynthesis`，手机上念出来是系统音色。
⇒ 改成调 `/api/voice/say` 拿桌面 kokoro 的音频，**音色跟卡片一致**。

## 四、实施阶段

### Phase 1 · 手机能说话的最小闭环（本轮先做）
1. `web.py` 的 `/api/voice/recognize` 加格式兜底（非 wav → ffmpeg 转 16k mono wav）。
2. 重写 `INDEX_HTML`：
   - 录音：`getUserMedia` + `AudioContext` → PCM 16k → WAV → 上传
   - 朗读：`/api/voice/say` → `<audio>`，失败回落 `speechSynthesis`
   - **免手模式**：录音 → 自动检测静音 1.2s 停 → 上传 → 回答 → 自动再录
   - 移动端适配：`100dvh`、安全区、44px 触控、大字号
3. `adb reverse` 打通，手机真机验收。

**验收**：手机上打开 `http://localhost:8765`，点一次麦克风授权后，
连续 5 轮不碰屏幕能对话；每轮转写错字 ≤2；静音自动收；说「退出」能停。

### Phase 2 · 先出先念（M3 完整）
1. `web.py` 加 `POST /api/chat/stream`（SSE 或 chunked 文本流）。
2. `dialogue` 加 `reply_stream()`：复用 `llm.stream()`，边生成边按句切。
3. 前端：收到第一句就请求 TTS 并播，同时继续收下一句（预取队列）。

**验收**：她开口延迟 ≤ 首句生成时间 + 1 段 TTS；断网切 kokoro 仍能说；无自激（自己念的被自己听到）。

### Phase 3 · 桌面端 M4 贾维斯收尾
- 状态灯（空闲/聆听/思考/说话）、打断（说话时按一下即停）、一键启动到首次对话 ≤60s。
- `desktop.py` 与 `web.py` 共用同一套 voice/dialogue 接口，不写第二份。

**验收**：启动到首次对话 ≤60s；连聊 20 轮不崩；说「切换到赛博」能换卡换音色。

### Phase 4 · 安卓端深化（可拔线）
- PWA：`manifest.json` + `service-worker`，加到主屏、全屏无地址栏。
- 自签 TLS：`web.py --tls`，手机信任一次证书。
- （可选）WebView 壳 APK：原生录音绕过安全上下文，彻底不依赖浏览器。

**验收**：拔掉 USB，手机主屏图标点开即用，免手 5 轮通过。

## 五、纪律（沿用铁律）

- **不许为通过验收改判据**。模型演不出来（M1 已证）就如实报「模型能力不足」，等更强模型。
- **不许静默失败**：录音拿不到权限、唤醒失败、TTS 失败，一律在界面上带原因说明。
- **不许摆死链**：界面上出现的每个按钮都必须真能用，否则不摆。
- 每阶段完成即跑 `run_selftests.py`，**58/58 不许掉**。
- 提交按文件逐个 add，**绝不 `git add -a`**。

## 六、风险与回退

| 风险 | 回退 |
|---|---|
| `adb reverse` 在某些 ROM 上不通 | 改 HTTPS 自签（Phase 4 提前） |
| 手机 Chrome 录音被系统省电杀 | 用 WebView 壳 APK（Phase 4） |
| whisper 对手机麦克风（远端拾音）识别率低 | 已证 4/4 通过的是本机麦；手机侧实测后若错字 >2/句，调 `initial_prompt` 热词 + 采样率，必要时换 small→medium |
| 本机 0.6B 演出差，手机端也差 | 如实报；手机可接远程 node1 的模型（`llm.py` 三后端抽象已可移植） |
