> 方法：电脑侧 `sweep.py` 全段扫描 → OUI 查证（macvendors + maclookup 双库）→
> 只读 banner 抓取（HTTP 头/标题/body、RTSP OPTIONS、telnet 欢迎语）→
> ONVIF `GetDeviceInformation`（无凭据标准 SOAP）→ 免费 LLM 交叉验证。
> **全部只读：未登录、未爆破、未尝试任何口令、未修改任何设备。**
> ONVIF 探测到认证墙即止（`.171` 任何 POST 都被踢到登录页，cookie 还嵌客户端 IP）。

## 一、环境结论（与 10-20 基线一致）

40 台设备中视频类 **22 台（10 车牌相机 + 7 海康 + 5 白牌 DVR）≈ 55%**——
这不是一户人家的网络，是**小区/商业楼共用的监控 + 宽带 NAT**，与隔壁邻居同段
（`192.168.0.0/24`，网关 `.16` = TP-Link YLWR1200G 易展版）。

## 二、四群「有疑问的」逐个拆解结果

### A 群 · `18:03:00` × 10 台（.101 .102 .107 .112 .120 .130 .131 .185 .186 .188）

**设备自报（硬事实，80 端口 body 原文）**：
```
app : 1.0.MT83001_I316D.SVR_PRIME_PS5260_DC_1080P_30FPS.20201109094359
algo: vdc<2.0.4899.ALG_C_Alpha-N-B_VDCA.200916>  vlpr<2.2.128125.ALG_VLPR_DLA_VDC_ALPHA.200415>
<!--axvdc.cab#version=1,1,9,8109-->
<meta http-equiv="Refresh" content="0;url=http://192.168.0.101:8000">
```

| 证据 | 解读 |
|---|---|
| `VLPR_DLA` 算法模块 | **Vehicle License Plate Recognition = 车牌识别** |
| `1080P_30FPS` | 1080P@30fps 抓拍规格 |
| `MT83001_I316D` / `PS5260` | 主板型号 + 安防 SoC 型号（工程机命名） |
| `20201109094359` | 固件编译于 **2020-11-09**，近 6 年未更新 |
| `axvdc.cab` ActiveX | 老式 IE 视频控件（VDC=视频数据采集） |
| meta refresh → :8000 | 真实 Web UI 在 **8000 端口**（`.120` 是 Vue 新版，其余 jQuery 老版） |
| 554 RTSP Public | OPTIONS/DESCRIBE/SETUP/PLAY/GET_PARAMETER/TEARDOWN（标准 NVR 面） |
| 9000 端口 | 海康系 SDK/私有协议端口特征（`.120/.130` 开，其余过滤） |

**结论（事实层）**：这不是家用摄像头，是**带车牌识别算法的道路/停车场抓拍摄像头**，
工程批量部署。OUI 在 IEEE 未注册（双库均查无）——白牌/贴牌/方案商出货的典型特征。
**厂商身份：LLM 推断为国产安防白牌（不确定具体品牌，不写名字）**——只认设备自报的
类型与规格，厂商名没有硬证据就不给。

### B 群 · `0C:38:3E` × 5 台（.171 .175 .176 .177 .178）

| 证据 | 解读 |
|---|---|
| 80: `Server: RapidLogic/1.1` + title `Logon` | RapidLogic 嵌入式固件（国产 DVR/对讲常用） |
| 554: `Server: H264DVR 1.0` | **H.264 硬盘录像机**（DVR），非 IPC |
| 登录页 16KB | XHTML + comm.js/xmlUtil.js/cookieUtil.js 三件套，典型国产 DVR 界面 |
| OUI = **Fanvil（深圳方位，VoIP 话机厂）** | **OUI 与实物不符** |

**结论（事实层）**：白牌 DVR/录像机。OUI 注册成 Fanvil 只是因为用了它家的**网络模组**
——**OUI 只代表网卡/模组注册方，不等于整机品牌**（本次最硬的一条新铁律实例）。
LLM 交叉验证同一结论。现 sweep 判定已从「摄像头 5 分」修正为「dvr 9 分」。

## 三、顺手固化的代码改进（都过门禁）

1. **`discovery.py` `fetch_http_banner` 加 `sig` 字段**：body 固件签名提取
   （vlpr/axvdc/VDCA/PS5260/MT83001/RapidLogic/H264DVR…）——title 常常是人人一样的
   `Welcome!`，Server 头常常是空的，身份在 body 里。
2. **`CATEGORY_RULES` 加两条硬规则**（权重 10/9，压过端口投票 5）：
   `RapidLogic|H264DVR → dvr`；`vlpr|axvdc|VDCA|SVR_PRIME|PS5260|MT83001 → camera`。
3. **`sweep.py` 接上真 banner**：原来传 `"http": ""` 空串，等于把最硬的
   「设备自报身份」证据整层扔掉了（这是它过去只能泛泛判「摄像头」的根因）。
4. **OUI 表加 `0C:38:3E → Fanvil(网络模组)`**（与在线库一致，注明是模组）。
