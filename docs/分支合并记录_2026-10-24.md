### 过程中的一个误报（记下来防止下次再踩）

git 对非 ASCII 路径默认八进制转义（`docs/\344\270\252...`），而盘点脚本里
`while read st f rest` 的 `read` **会吃掉反斜杠**，转义被还原成「数字名」，
一度误报「main 缺此路径」。用 `git -c core.quotepath=false` 才拿到真名。
另：MSYS/Git Bash 会把 `origin/feat/x:file` 这种冒号语法转换成
`origin\feat\x;file`，比 blob 必须用 `git diff A B -- path` 绕开。
