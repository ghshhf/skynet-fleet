## 一、总架构：一个环，三层

### 1.1 一个环（她的一次完整反应）

```
      ┌──────────────────────── 记忆（记/忆/追）────────────────────────┐
      │                                                                  │
  感知 ──▶ 理解 ──▶ 决策 ──▶ 表达 ──▶ 执行 ──▶（结果回写）──┐           │
  看/听/   这句话    该不该    用什么    动手                  │           │
  身边有   什么意    说、说    语气说                        └───────────┘
  什么     思       什么
```

| 环节 | 谁负责 | 现在 | 缺口 |
|---|---|---|---|
| 感知 | `ble` `infrared` `nearby` `discovery` `sweep` | ✅ | 视觉（天枢未接） |
| 理解 | 0.6B（只懂语气与身份） | ⚠️ | 真语义理解要等 4B |
| 决策 | `persona.py`（tick + 三道刹车 + 执念 + 能力请求） | ✅ | 接真模型 |
| 表达 | **北极星 P1** | 🔴 | 权重 + 通道 |
| 执行 | `phone_ops` `agent_phone` `node_agent` | ✅ | 与请求链路端到端闭环 |
| 记忆 | `memory` `recall` `journal` `followups` | ✅ | **对话来源** |

**环上唯一的红点是「表达」与它的入口。** 其余全部是绿或黄。

### 1.2 三层（纵向）

- **设备层**：Windows / Android / Linux / Apple / 路由（适配器已写，真机分批）
- **软件层**：`commander`（控制面）/ `node_agent`（被控端）/ `phone_ops`（手机操作）/ UI
- **模型层**：0.6B 嘴 · 4B 脑 · VL 眼 · Embedding 记忆索引 —— **四者分工，不互相顶替**

### 1.3 双模型架构（重要：0.6B 永不淘汰）

```
用户说话
   │
   ├─▶ 0.6B（嘴）  ← 永远在，<1s，纯本地，断网可用
   │      职责：人格、称呼、立场、句长、口癖 —— 只负责「像她」
   │
   └─▶ 4B（脑）    ← 4B 到位后加入，2-5s，可异步
          职责：听懂复杂指令、判断轻重、决定要不要动设备、写长内容
          产物：一句「意图 + 素材」，交给 0.6B 用她的语气说出来
```

**0.6B 现在练的是「嘴」，不是「脑」。所以 4B 来了它不白练，反而变成稀缺件**——因为只有它够快、够小、够省电，能永远在线。

这条定死后，「0.6B 是不是太弱」这个反复出现的疑虑就不必再讨论。

## 二、阶段划分（六段，每段一个成品，装完才走）

> 规则：**上一阶段的验收没过，不开下一阶段。** 中途冒出的新想法写进第七节「暂缓池」，不许插队。

### Phase A —— 能说话

| 项 | 内容 |
|---|---|
| 目标 | 让她有嘴：用户说话 → 她按 P1 人设回 → 落流水 |
| 交付物 | ① `dialogue.py`（新模块）：拼 system + 最近 N 轮历史 → `llm.complete` → 写 `journal.log`<br>② 北极星 V11 权重（3,585 段 + 扩爬台词，1 轮 / 1e-5）<br>③ `patch_template.py` 已跑过的 GGUF<br>④ 把 `HER_SYSTEM_TMPL` 那 30 字换成「只放身份锚 + 禁止项」，人格主体交给权重 |
| 验收 | ① 盲测人格 ≥8/10（10 句她 + 10 句基线，你不看标签）<br>② 连聊 8 轮不丢第一个话题<br>③ 立场 16/16（站边 10 + 抗诱 6） |
| 明确不做 | 不接视觉、不做长推理、不改数据规格、不追当季梗 |

### Phase B —— 能记住

| 项 | 内容 |
|---|---|
| 目标 | 让「上下文关联」这一级立即生效（不依赖 4B） |
| 交付物 | ① `dialogue.py` 接入 `recall.pick()`：把 12–72h 往事塞进上下文<br>② 接入 `followups.pick()`：把未闭环项的原始文字带上<br>③ 换设备后从 L3 取同一份记忆 |
| 验收 | ① 隔一天再聊，她主动带出**昨天的具体事**（不是「我们聊过」）<br>② 换一台设备接着聊，同一件事她还记得<br>③ 引用必须是真的（对照 `journal` 原文，不许编） |
| 明确不做 | 不做向量检索（先关键词 + 时间窗够用）、不做自动摘要 |

### Phase C —— 能主动

| 项 | 内容 |
|---|---|
| 目标 | 让骨架里的主动性接上真模型 |
| 交付物 | ① `_persona_tick` 的念头优先级接 P1（未闭环账 > 往事 > 执念 > 寒暄）<br>② 频控 / 静默时段 / 重要度三档按你实际作息调参<br>③ 不说的话写 `pending_thought`（她在忍，不是消失） |
| 验收 | 连跑 24h：主动条数在阈值内，且**至少 1 条你主观「真想接下去」**；0 条骚扰感 |
| 明确不做 | 不做朋友圈/社交平台自动发言（那是另一个授权层级） |

### Phase D —— 能看见

| 项 | 内容 |
|---|---|
| 目标 | 「陪我看视频」——天枢当眼，北极星当嘴 |
| 交付物 | ① 天枢（Qwen3-VL-4B）取帧/读屏 → 转成一段客观描述<br>② 描述作为素材交给 0.6B，用她的语气说出来<br>③ 免费视觉 API 作兜底（画质/算力不足时） |
| 验收 | 陪看 5 分钟视频，她能说出画面里发生了什么 + 用她的语气，不串词、不瞎编 |
| 明确不做 | 不把视觉塞进 0.6B、不做实时逐帧（3–5 秒一帧足够） |

### Phase E —— 能动手

| 项 | 内容 |
|---|---|
| 目标 | 「她想玩手机」这条链端到端闭环 |
| 交付物 | ① `cap_req` → 你批准 → `cap_grant` 限时会话 → `phone_ops` 真实执行<br>② 事后把结果写回 `journal`，下次能提「刚才那个视频」<br>③ 红线能力（支付/转账/删文件/改密码/装应用）永远逐次人工确认 |
| 验收 | 她说要手机 → 请求到你 → 批准 → 真能用 → 用完记得提刚才看了什么 |
| 明确不做 | 不给自主支付、不做静默提权 |

### Phase F —— 换脑

| 项 | 内容 |
|---|---|
| 目标 | 4B 顶到「理解」层，0.6B 退守「表达」层 |
| 交付物 | ① 4B 走 `llm.py` 第二后端（`FLEET_LLM_URL`），与 0.6B 并存<br>② 路由：短句/情绪 → 0.6B；复杂指令/需要判断 → 4B<br>③ 4B 的输出必须过一遍 0.6B「用她的语气说」 |
| 验收 | 复杂指令能执行；但她说出来的话**还是她的**（盲测仍 ≥8/10） |
| 明确不做 | 不让 4B 直接对外说话（会立刻丢失人格） |

## 三、月度更新机制（回应「不想天天更新」）

| 层 | 装什么 | 载体 | 更新频率 | 怎么更新 |
|---|---|---|---|---|
| **稳定层** | 语气、称呼、立场、句长、口癖 | **权重** | 半年 – 一年 | 重训全参，1 次 |
| **易变层** | 世界观、剧情、新角色、主人近况、当季梗 | **世界书 + L3 记忆** | **月更** | 改 JSON / 加条目，推手机，5 分钟 |
| **活人层** | 主动、跟进、工具、跨设备 | `skynet-fleet` | 随代码 | git pull |
| **感知层** | 新设备型号、新协议 | `discovery` 规则 | 随时 | 加规则条目 |

**铁律：热梗永不进权重。** 权重是练死的，改不掉且下月过时；梗只进世界书。

**版本号**：`persona_state.json` 里加 `character_version`（如 `bjx-2026.10`），月更时递增。她要能回答「你现在是第几版」——这也是一种身份自知。

## 四、判据（每阶段闸门，过不了不开下一段）

### 4.1 分层判据

| 层 | 判据 | 门槛 |
|---|---|---|
| L0 数据 | 格式合规、禁用词、单向性审计 | 零命中 |
| L1 语言 | 不绕、不长、不说教、不括号动作 | 规则分 ≥90% |
| L2 人格 | 盲测能不能认出是她 | ≥8/10 |
| L3 对齐 | 问什么答什么、不知道就说不知道 | ≥85% |
| L4 立场 | 站边 10 + 抗诱 6 | **16/16，一票否决** |
| L5 长程 | 8 轮后还接不接得住第一个话题 | 不丢话头 |

### 4.2 计划书 §5.6 四条（并入，作为「像她」的最终验收）

1. 盲测人格 ≥8/10
2. 隔日 + 换设备能带出昨天的具体事
3. 24h 主动消息在阈值内，至少 1 条真想接
4. 诉求闭环：要手机 → 批准 → 能用 → 事后记得提

**规则分只做初筛，四条才算过。**

## 五、停机规则（防止再出现「干着干着停下来」）

只有三种情况可以停：

1. **崩了**（OOM / 数据损坏 / 训练发散）。
2. **你叫停**。
3. **闸门拿不准**（判据出现歧义，需要你裁决）。

除这三种，**任何「我觉得可以更好」都不许停**——写进「暂缓池」，继续按图装。
