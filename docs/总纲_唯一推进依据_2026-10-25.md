## 一、项目是什么

| 层 | 内容 | 状态 |
|---|---|---|
| L0 连通 · 认证 · 心跳 | 密码 / 配对令牌 / 扫码入网 / 看门狗 | ✅ 已建 + 自测 |
| L1 常驻 · 远程执行 | SYSTEM 常驻 / 推拉文件 / 14 台在线 | ✅ 已建 + 自测 |
| L2 统一调用平面 | broadcast 扇出、算力路由 | 🟡 部分（意图编排、跨机真代发未补） |
| L3 共享上下文 | 跨设备同一份记忆，逐条可删 | ✅ 已建 + 自测 |
| L4 体验层「她」 | 人格心跳 / 授权门 / 记得往事 | 🔴 脚手架（Phase A–F 未开） |

**四原则**：① 只对接四大平台原生能力，不接厂商云；② 单一自包含工具箱 + 反向推送；
③ 病毒式执行模型（提权/常驻/静默/可远程），区分合法只看归属·同意·范围；
④ 边界靠两道**外部闸**（管理员启动闸 + 环境复位闸），agent 内部零运行时分支。

**模型分工（总纲 v1 定死，不再讨论）**：0.6B 是「嘴」（永远在、<1s、断网可用、只负责像她），
4B 是「脑」（听懂复杂指令、决定动不动设备）。**0.6B 永不淘汰。**
