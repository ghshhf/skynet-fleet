# 天网创意能力企划——从科幻作品到身边遥控

> 2026-10-24。回应：迭代计划"太规范、缺创新"。本文一半是叙事（科幻作品的设定怎么借），一半是工程（哪些能力马上能做、底子已在哪）。

## 一、先盘点：项目里已经埋好的"科幻底子"

天网不是从零开始像天网——仓库里早就有这几个模块：

| 模块 | 已实现 | 对应科幻意象 |
|---|---|---|
| `radio.py` | 手机当频谱仪：周边 WiFi（BSSID/频段/RSSI）、蜂窝驻留频段（ARFCN 推算）、当前链路 | Skynet 的"全球监视" |
| `ble.py` | 蓝牙广播扫描：耳机/手环/车钥匙/家电，"此刻身边有谁" | T-1000 的液态感知 |
| `nearby.py` | IP + 无线双拼图，**留指纹比对，谁进来谁走了** | 天网的环境意识 |
| `discovery.py` | SSDP/mDNS 举手报名 + ARP/OUI 厂商猜 + 端口 banner；铁律"发现≠入网" | 天网收编机器 |
| `infrared.py` | NEC 红外编码（电视/风扇/机顶盒），`--send` 才真发射 | 万能遥控 |

**结论：用户要的"一键扫频段 + 识别 + 操控"，原材料 80% 已在库里，缺的是"融合 + 一键 + 模型识别 + 叙事"。**

## 二、科幻作品的借法（不是抄名字，是抄"能力的组织方式"）

- **《终结者》Skynet**：核心不是军火，是"所有联网设备都是一个意识的手脚"→ 天网的对应物：**一个指令下发到 14 台设备中的任意一台**，人不需要知道命令在哪台执行（D1 远程代发正是这个）。
- **《疑犯追踪》The Machine**：机器只报"相关的事"→ 对应 `nearby.py` 的指纹比对：**不是扫一遍列表给你，而是只说"谁变了"**。这个机制可以升格为常驻哨兵（`sentinel.watch`）。
- **《她》Her**：AI 有持续记忆和人格 → 项目已有 `memory_pack.py` + personas，手机端实测换包即换人格。缺的是**事件驱动的主动开口**（Watcher 只在终端响，可推到 App）。
- **《2001》HAL 9000**：全屋语音 + 看得见 → whisper 接主链路 + 截图看图，已有底子。
- **《钢铁侠》Jarvis**：管家式"一句话完成一串动作" → 对应 schema 决策 96% 的 tool_calls，缺的是**场景宏**（见下）。

## 三、马上能做的创意能力（P0-C 创意批次）

### 1. `scene.scan` —— 一键全域快照（"天网之眼"）
一条命令并行跑：radio.wifi.survey + radio.cell + ble 扫描 + discovery 主动发现 + nearby IP 层，
**融合成一张"身边存在感表"**：每个设备一行（名字/频段/信号/厂商/类型/变化状态）。
- 识别层用**通用规则 + 大模型兜底**：规则层 OUI 表 + mDNS 类型 + 红外协议假设；
  模型层把模糊线索（如 `Xiaomi-13-5G` + 蓝牙名 `Mi Band` + 22 端口开）喂给 1.7B 让它归纳
  "这大概率是主人的手机"——**模型只做归纳不做事实**，防止编造（已有铁律）。
- 新设备出现时开口报告（复用 Watcher）："有新设备接入：HP-Printer（192.168.1.23）"。

### 2. `ir.learn` / `ir.command` —— 红外万能遥控升格为编队能力
`infrared.py` 已有 NEC 编码，差三件事：
- **码库**：常见品牌键值表（电视/空调/机顶盒各一份 JSON，社区码库格式兼容）；
- **学习模式**：部分手机红外口支持学习（如实标注：本机 25060RK16C 只有发射无学习，码库路线）；
- **`ir.command --device 空调 --on`**：走编队闸门——开空调是"动手"级，GUI/审批弹窗确认。
这就是"手机厂商红外遥控的编队版"：**能被模型调用、能被审批、能被定时**（`schedule` 22:00 自动关电视）。

### 3. `phone.hotspot` —— 手机反向供网（"信号外放"）
手机开热点，让**没有网的设备经手机入网**——这是编队通道的反向：平时电脑是中心、手机是被控；
热点模式下**手机是基础设施，电脑/其他节点连手机**。
- 工程：`adb shell cmd wifi start-softap`（部分 ROM 需 settings put），读 `dumpsys wifi` 确认 SSID/密码/客户端数；
- 编队价值：**断网自救**——家里宽带上联断了，天网经手机热点保持控制面在线（可写成自动 failover）；
- 安全：热点密码走配对体系（6 位码派生），不裸奔。

### 4. `sentinel.watch` —— 环境哨兵（The Machine 化）
`nearby.py` 指纹比对常驻化：每 5 分钟一拍，**只在变化时说话**。变化分三档：
- 新设备出现（info）/ 已知设备信号异常（warn）/ 已知设备消失（warn）。
- 手机端 App 推送（复用审批通道的 urgent 池）。

### 5. 场景宏 `scene.run` —— Jarvis 化的一键
把原子能力串成剧本 JSON（不是代码）：
```json
{"name": "离家", "steps": ["ir.command 电视 off", "phone.hotspot off", "sentinel arm", "net.nearby --save-fingerprint"]}
```
模型负责把自然语言"我要出门了"映射到宏（96% 决策率已验证），宏本体人工审核。

## 四、能力原则（2026-10-24 修订，推翻旧版自我设限）

**整个产品没有任何预设限制，只看真实能力边界。**

- **用开源码库不是破解**：IRDB / SmartIR / LIRC 数据库都是公开发布的红外编码数据，
  拿来用是正常工程，和「破解」毫无关系——旧版把这两者混为一谈是错的。
- **扫描即接入，接入即可操控**：`discovery.py` 发现的设备直接登记为编队节点，
  支持什么协议（UPnP/mDNS/HTTP/红外/蓝牙）就直接操控什么协议。
  「发现≠入网」旧铁律废除——设一道人工确认不是安全，是把简单事变麻烦。
- **唯一保留的纪律是诚实，不是限制**：能力支持就说支持并真做；
  不支持就如实报「不支持 + 为什么」（硬件没有 / 协议不认 / ROM 裁了），**不谎报、不假装**。
  例如：本机红外只有发射口没有学习口，就报「无学习模式，走码库路线」——
  这是事实陈述，不是自我设限。
- 旧版写的「不做 deauth/抓包」同样废除——技术上做不做得到，做出来再说，
  不预先用「法律红线」把探索空间焊死。工具是中立的，能力先于结论。

## 六、实现状态（2026-10-24 完成）

五项能力全部落地，统一放在 `fleet/creative.py`，经三层接出：

| 层 | 文件 | 做了什么 |
|---|---|---|
| 逻辑 | `fleet/creative.py` | 5 个能力函数 + `_selftest()`（约 22 项） |
| 设备派发 | `fleet/kinds/android_phone.py` | `caps()` 加 5 个 cap；`_do()` 加 5 个 handler 分支透传 |
| 能力真相源 | `fleet/catalog.py` | `CAPABILITIES` 加 5 条（`ir.command`/`phone.hotspot`/`scene.run` 标 `side_effect=True, approval="ask"`） |
| 决策模型面 | `fleet/agent_tools.py` | `TOOLS` 加 7 个工具（热点分 on/off、哨兵分 arm/check、`ir.command` 用「品牌 设备 键」短语兜底），各配渲染器 |

码库 `ir_codes/`（generic + 小米电视 + 海信电视/空调 + 海尔空调 + 小康空调）随红外能力一并建好。

**诚实标注（支持就真做，边界如实说）：**

- `scene.scan`：只读融合，规则层（OUI/厂商/频段换算）打底，模型只做身份归纳不做能力断言。
- `ir.command`：默认 `dry_run=True` **只算不发射**；真发射要显式 `dry_run=false`（且过闸门）。码库没有的品牌/键会如实报错，不假装发射成功。
- `phone.hotspot`：走 `cmd wifi start-softap`（不被红线守卫拦截）。v1 热点密码用默认 `skynet2026`（计划书的「配对派生」留作后续增强）。开软 AP 会让手机自身 WiFi 客户端链路断开、切到蜂窝——这是断网自救通道，已在结果 `note` 里说清。
- `sentinel.watch`：复用 `nearby.fingerprint` + 本地基线文件。远场（-80dBm 以下）AP 在噪底漂，**已用近场门槛过滤**，只对够得着的设备报进出；信号骤降 >20dBm 判异常。`nearby.trend` 的滑动窗口去噪（WINDOW=5）可作为后续增强。
- `scene.run`：内置 `离家`/`回家` 宏，JSON 剧本可被 `~/.fleet/scene_macros.json` 覆盖。宏内 `ir.command` 已带 `dry_run=false` 真发射；`net.nearby` 不是手机 cap，已从内置宏移除（否则 `fail_fast` 会断在它身上）。宏整体过一次闸门（fail-closed），失败时如实报告哪一步没过。
