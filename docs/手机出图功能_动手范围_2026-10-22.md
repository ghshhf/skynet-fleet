# 手机出图功能（N+1c）· 动手范围 · 2026-10-22 21:2x

> 依据：《手机算力节点_计划书_2026-10-22.md》v1 期（已拍板：先出图）。
> 主人原话：「上午安装的天网 App 现在只有语音对话，更新进去出图功能……先把出图下放……搜索开源项目，然后就干」。
> 本文只记录**范围与契约**；实施按任务清单逐步过闸。

## 1. 一句话

天网 App 加「出图」入口：手机上输 prompt → **Termux 里 stable-diffusion.cpp（Vulkan）本地出图** → 结果落相册 Pictures/fleet → App 内展示。APK 不装模型、不装 .so、不加网络出口。

## 2. 为什么是 Termux 路线（调研结论，2026-10-22）

| 路线 | 结论 |
|---|---|
| App 内 JNI 直跑 sd.cpp（NDK+Vulkan） | ❌ v1 不做：NDK 构建链、VkDevice 从 Java Surface 拉起、2GB 模型管理——工作量按天算，违背「一步一个脚印」 |
| **App → RUN_COMMAND → Termux → sd.cpp** | ✅ 选它：契约已从 termux-app v0.53 源码核实（见 §4）；APK 仍是百 KB 级；sd.cpp/模型都在 Termux 侧可版本管理；与计划书「Termux 原生 Bionic + 系统 Vulkan ICD」一致 |
| App → 电脑 FleetServer 出图 | ❌ 违背「下放」：本机无独显，出图正是最该 offload 的活 |

开源基座：`leejet/stable-diffusion.cpp`（MIT，纯 C/C++，gguf 模型，Vulkan 后端支持 Mali/Immortalis）。社区先例：Termux 可编译，S23 默认参数 70s/it（无 GPU 加速时）；Vulkan 绑定正确时数量级提速（第三方自报 S25 10 步 32s，**待我方 K80U 实测复核**）。

## 3. 三段契约

### 3.1 App → Termux（RUN_COMMAND，源码核实版）

```
intent.setClassName("com.termux", "com.termux.app.RunCommandService")
intent.setAction("com.termux.RUN_COMMAND")
extras:
  com.termux.RUN_COMMAND_PATH      = /data/data/com.termux/files/home/fleet/fleet-img.sh
  com.termux.RUN_COMMAND_ARGUMENTS = String[]{"--prompt", "...", "--steps","10","--seed","","--size","512"}
  com.termux.RUN_COMMAND_WORKDIR   = /data/data/com.termux/files/home/fleet
  com.termux.RUN_COMMAND_BACKGROUND = true      // 后台跑，通知栏看实时日志，App 不切走
  com.termux.RUN_COMMAND_PENDING_INTENT = PendingIntent.getBroadcast(本App 显式 Receiver, FLAG_MUTABLE|FLAG_UPDATE_CURRENT)
```

结果（PendingIntent 回传，bundle 在 intent extra `"result"` 里）：`stdout`（String）/ `exitCode`（int）/ `err`（int，-1=无内部错）/ `errmsg`。stdout+stderr 合并回传上限 100KB——**所以 fleet-img.sh 的 stdout 只许打一行 JSON**（见 3.2）。

前置条件（缺任一 → App 给出精确指引，不静默）：
1. 装了 Termux（F-Droid 版，Play 版已废弃）
2. manifest 声明 `com.termux.permission.RUN_COMMAND` + `<queries><package android:name="com.termux"/>`
3. `adb shell pm grant app.skynet.tianwang com.termux.permission.RUN_COMMAND`（或设置里手授）
4. Termux `~/.termux/termux.properties` 有 `allow-external-apps=true`
5. Termux 电池优化=无限制 + `termux-wake-lock`

### 3.2 fleet-img.sh（Termux 侧 worker）契约

- 入参：`--prompt`（必填，1–500 字符）/ `--steps`（1–30，默认 10）/ `--seed`（整数或空）/ `--size`（512|768|1024，默认 512）
- 纪律闸门（fail-closed，全部带原因）：
  - sd.cpp 二进制不存在 → exit 2 + err 指明跑 setup 脚本
  - 模型不存在 → exit 2 同上报
  - 未插电（`/sys/class/power_supply/battery/status` 非 CHARGING/FULL/NOT_CHARGING）→ 拒；`FLEET_IMG_ALLOW_BATTERY=1` 可放开
  - 机身温度 > 42°C（max thermal zone，可配 `FLEET_IMG_MAX_TEMP`）→ 拒
  - 锁文件 `~/.fleet-img.lock`：第二张并发 → exit 3「上一张还没画完」
- 执行：调 `$SD_BIN`（默认 `~/sd.cpp/bin/sd`）ggml 自动选 Vulkan 后端；输出 PNG 到 `~/storage/shared/Pictures/fleet/fleet-<ts>-<rand>.png`
- stdout 唯一一行：`{"ok":true,"path":"...","ms":123,"temp":41.2,"steps":10}`；失败 `{"ok":false,"err":"原因"}` + 非零 exit
- **测试注入点**（诚实可测）：`FLEET_IMG_BATTERY_DIR` / `FLEET_IMG_THERMAL_GLOB` / `FLEET_IMG_SD_BIN` / `FLEET_IMG_MODEL` 环境变量覆盖，门禁用假 sysfs 测闸门

### 3.3 App ← 相册（结果回取）

- worker 把 PNG 写进 `Pictures/fleet/`（相册直接可见，顺手解决「保存」）
- App 用 MediaStore.Images 查询该目录最新一张 → InputStream 解码展示（inSampleSize 防 OOM）
- 权限：API 33+ 运行时申请 `READ_MEDIA_IMAGES`；≤32 申请 `READ_EXTERNAL_STORAGE`（与 RECORD_AUDIO 同款模式）
- 进度：后台模式 stdout 结束才回 → App 内显示已等秒数 + 提示「Termux 通知栏有实时日志」（v1 诚实边界：App 内无逐行进度，v1.1 再议）

## 4. 已核实的 Termux 契约（termux-app v0.53 源码，2026-10-22 拉取）

- action `com.termux.RUN_COMMAND`；service `com.termux.app.RunCommandService`
- `com.termux.RUN_COMMAND_PATH`（String）/ `_ARGUMENTS`（String[]）/ `_WORKDIR`（String）/ `_BACKGROUND`（boolean）/ `_PENDING_INTENT`（Parcelable）
- 结果 bundle key：`result` → `stdout`/`exitCode`/`err`/`errmsg`（`err=-1` 为无内部错误）
- PendingIntent 需 ≥0.109；`FLAG_MUTABLE`（Termux 要往回传 intent 填结果）
- 100KB 截断、TransactionTooLarge 不可捕获 → 单行 JSON 设计即为此

## 5. 诚实边界（写进验收报告）

1. **Vulkan 是否真生效以实测为准**：ggml 启动日志打印后端名；setup 脚本强制要求日志里出现 Vulkan 设备名，否则报「仍在 CPU 上跑」并给出排查步骤（Termux 自带 Mesa wrapper 冲突是已知坑）。
2. **Immortalis-G925 的 FP16 denormal 绿图坑**：Mali/ARM 架构已知问题，需 FTZ；出图后 App 内提供「重出（换 seed）」入口便于对照。
3. **App 内无实时进度条**（见 3.3）。
4. **持续出图必热降频**：worker 温度闸门只做「开跑前」检查，10 分钟连续出的帧率曲线留待真机实测记录。
5. **模型下载 1.1GB 级**（SD1.5 q8_0）需主人认可；setup 脚本先问再下。
6. D2 独显/NPU 仍摸不到（计划书已列红）。
