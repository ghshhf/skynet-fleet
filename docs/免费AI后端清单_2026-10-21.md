## 0. 结论先行

1. **真正「零配置、连账号都不用注册」且能跑通 OpenAI 协议对话的，本机实测只有两个**：pollinations（`https://text.pollinations.ai/v1`）与 OVHcloud AI Endpoints（`https://oai.endpoints.kepler.ai.cloud.ovh.net/v1`）。其余所谓「免 key」端点要么只给模型列表、要么要 key、要么是第三方聚合站。
2. **pollinations 的免 key 限流是「每 IP 一次、至少间隔 30 秒」**（官方 APIDOCS.md 原文），超了返回 402 + `Retry-After`。这意味着它**只能当心跳/兜底，不能当主力对话通道**。**【双源：官方 APIDOCS.md + freellmapi provider 注册表注释「1 concurrent per IP」】**
3. **OVH 匿名层官方口径是 2 requests/minute per IP per model**（第三方实测复核）；**本次实测匿名对话 200 成功、模型列表免 key 可列 13+ 个模型**。但其公开定价页对 Qwen3.6-27B 等仍标了单价，匿名层是「限流试用」而非「永久免费额度」，随时可能收紧。**【实测 + 双源】**
4. **项目里 `fleet/ai_backends.py` 的 llm7 配置已经过期**：硬编码的 `model: "gpt-4o-mini"` **已不在 llm7 当前的 70 个模型列表中**（2026-10-21 免 key 拉 `/v1/models` 确认，`gpt-4o-mini` 命中为 false）。当前 turbo 档有 7 个：`gpt-oss:20b`、`GLM-5.3-Flash`、`DeepSeek-V4-Flash-0731`、`codestral-latest`、`minimax-m2.7`、`mistral-Nemo-Instruct-2407`、`nemotron-3-nano:30b`。**【实测】**
5. **llm7 现在没有零价模型**：70 个模型里 61 个 `usage_based_only: true`，tier 只有 `turbo`(7) 与 `pro`(63)，**无 `free` 档**。匿名对话实测返回 **429 `quota_exceeded`（retry_after ≈ 64898 秒）**。也就是说 llm7 已经不是免费后端了，**只当「有 token 才活」的付费兜底**。**【实测】**
6. **免费层第一梯队（拿 key 即可、不绑卡、额度按天/按月重置）**：OpenRouter `:free`（累计购买 <$10 时 50 RPM / 50 RPD）、Groq free plan（gpt-oss-20b 30 RPM / 1K RPD / 8K TPM / 200K TPD）、Google AI Studio（免费层内容会被用于改进产品）、Cloudflare Workers AI（10,000 Neurons/天，00:00 UTC 重置）。**【多数双源】**
7. **国内唯一「长期免费、不限量、只限并发」的官方档是智谱的 GLM Flash 系列**：GLM-4.7-Flash（200K 上下文、128K 最大输出、**并发 1**）、GLM-4-Flash-250414、GLM-4.6V-Flash、GLM-4.1V-Thinking-Flash、GLM-4V-Flash、GLM-Z1-Flash。GLM-4.5-Flash 已于 2026-01-30 下线并自动路由到 GLM-4.7-Flash。**【双源：官网文档 + 官方定价页 + 多篇社区实测】**
8. **智谱的并发 1 是本项目最大的结构性约束**：一个常驻人格 + 一次长回复就可能占满整条通道。**若要「一直在线」，智谱只能做兜底，不能做主力。**
9. **ModelScope（魔搭）是国内最干净的「按天重置」免费层**：每用户 **2000 次/天**，单模型 **500 次/天**（DeepSeek-R1-0528 / DeepSeek-V3.2-Exp 等大模型只给 100 次/天）。但**必须绑定阿里云账号且完成实名**。响应头可查 `modelscope-ratelimit-requests-remaining`。**【双源：官方 limits 文档 + 魔搭官方头条文章】**
10. **阿里云百炼的新人额度是「每模型 100 万 Token、90 天有效」，不是「每月 100 万」**——社区流传的「每月 100 万 token 长期有效」是**错的**。而且**仅华北 2（北京）地域有免费额度**，其他地域没有。**【双源：官方《新人免费额度》文档 + 第三方整理】**
11. **百炼的免费额度「用完即停」对未实名用户是强制开启、不可关闭的**——这恰好是我们想要的形态（不会意外扣费），但反过来说实名后默认关闭，需要手动打开。**【官方文档】**
12. **零一万物（01.AI）开放平台已经死了**：2026-08-03 公告「即日起停止新用户注册及充值」，**2026-09-03 24:00 起停止 API 调用**，退款申请窗口开到 2026-12-03。本报告写作日（2026-10-21）**API 已不可用**，不要再把它列入备选。**【双源：官网公告 + 凤凰科技 + i黑马】**
13. **火山方舟（豆包）的「50 万 Token」不是永久免费**：安心体验模式是账号级配置，仅消耗赠送的 50w token，**接近耗尽服务自动暂停**；不开启则直接转按量计费。协作奖励计划的「每日 200 万」需在开通管理页手动加入，且企业认证是 500 万/单模型。**【官方文档】**

15. **Kimi（月之暗面）没有永久免费层**：新用户完成实名后赠 **15 元代金券，有效期 3 个月**；用完从充值余额扣费，余额为零时 API **返回 403**。且该券**不能用于体验 Kimi K3**。**【官方《免费测试权益》页】**
16. **讯飞星火 Spark Lite 是「唯一带联网搜索的免费模型」**：base_url `https://spark-api-open.xf-yun.com/v1`，model 填 `lite`，永久免费不限量（有效期到 2036 年），并发 5。**但鉴权用的是控制台「APIKey:APISecret」冒号组合串**，且**不支持 FunctionCall / 图片输入 / 推理模式**。**【双源：官方 HTTP 接口文档 + 第三方实测截图】**
17. **本机（i5-12450H + 16GB 单通道 DDR4）跑本地模型的天花板极低**：214M F16 → 24.2 tok/s，Qwen3-4B Q4_K_M → 3.86 tok/s。**结论：本地模型只能做「断网兜底 / 敏感数据不出网 / 工具调用的确定性小脑」，不能做主对话通道。**
18. **给本项目的最终建议（网关之外只备 3 个直连）**：
    - **主力**：本地网关 `http://127.0.0.1:8787/v1`（已有 51 条 / 17 个唯一 model id，全部 `:free` 或 free 别名）；
    - **备一（国内、不绑卡、永久免费）**：智谱 `https://open.bigmodel.cn/api/paas/v4` + `glm-4.7-flash`；
    - **备二（国内、按天重置、免充值）**：ModelScope `https://api-inference.modelscope.cn/v1` + `Qwen/Qwen3.5-35B-A3B`；
    - **备三（国际、零配置、兜底）**：pollinations `https://text.pollinations.ai/v1`（**只做心跳与最后兜底，30 秒 1 次**）。
    - 选型详情见 §6。

## 3. 本地免费方案与本机天花板

### 3.1 本机硬件与实测

| 项 | 值 |
|---|---|
| CPU | Intel Core i5-12450H（8 核 4P+4E） |
| 内存 | 16 GB **单通道 DDR4** |
| GPU | 核显 Intel UHD（无独显） |
| 实测 · 小模型 | 214M F16 → **24.2 tok/s** |
| 实测 · 中等模型 | Qwen3-4B Q4_K_M → **3.86 tok/s** |
| 本机当前状态 | **未安装 ollama / llama-server / lms**；`127.0.0.1:11434` 与 `127.0.0.1:1234` 实测均无响应（`curl` 返回 000） |

### 3.2 天花板推论

- **3.86 tok/s 的含义**：一次 300 token 的回复需要 **约 78 秒**；一次 1000 token 需要 **约 4.3 分钟**。**完全不适合交互式对话。**
- **单通道 DDR4 的额外惩罚**：llama.cpp 的 prompt 处理（batch）会吃满内存带宽，**首 token 延迟（TTFT）远高于 tok/s 所暗示的水平**。24.2 tok/s 的 214M 模型虽然快，但**智力不足以承担「她」的人格扮演**。
- **核显 + 单通道**：`-ngl auto` 只能卸载少量层到核显，收益有限；实际应以 `--device none`（纯 CPU）+ `--threads 8` 为基线，**并把 `--ctx-size` 压到 2048～4096**（上下文 KV cache 是 16GB 机器上的主要内存占用）。
- **结论**：本地模型在这台机器上的合理定位是——

| 用途 | 本地是否胜任 |
|---|---|
| 意图分类 / 关键词抽取 / 工具参数抽取 | ✅ 胜任（214M 级别足够） |
| 断网时的最后兜底回复 | ✅ 勉强（模板化回复） |
| 多轮对话人格扮演 | ❌ 不胜任（延迟不可接受） |
| 长上下文摘要 | ❌ 不胜任（TTFT 过高） |
| 隐私数据不出网 | ✅ 唯一不可替代的价值 |

### 3.3 三种本地运行时的取舍

| 维度 | Ollama | LM Studio | llama.cpp server |
|---|---|---|---|
| 装起来最省事 | ✅✅ | ✅（GUI） | ❌（需下载编译/预编译包） |
| 内存控制 | 差（常驻） | ✅（Idle TTL 自动卸载） | ✅✅（`--parallel` slot + `--ctx-size`） |
| OpenAI 兼容完整度 | ✅（含 `/v1/responses`） | ✅（`/v1/chat/completions` + 原生 `/api/v1/*`） | ✅✅（含 `/v1/responses`、`/v1/embeddings`、`/reranking`） |
| 无状态/有状态 | 均无状态 | 原生 `/api/v1/chat` **支持有状态会话** | 均无状态 |
| 离线可用 | ✅ 模型下到本地 | ✅ | ✅ |
| 对本项目最合适 | 作为**长期常驻服务**（有 web UI 看日志） | 作为**模型切换实验台** | 作为**生产用可控服务**（key 鉴权、slot 控制、ctx 精确） |

## 6. 选型建议：「她要一直在线、免费、要能操控本机」

### 6.1 三个硬约束

1. **「一直在线」= 高频调用**。按 1 次/5 秒的对话节奏，一天就是 ~17,000 次请求。**这直接排除了所有按 RPD 计的小额免费层**（OpenRouter 50 RPD、Groq 1K RPD、Gemini 1,500 RPD、DeepSeek/百炼/混元的一次性额度）。
2. **「免费」= 不能有意外扣费**。凡是「额度用完自动转按量计费」的（百炼实名后、豆包安心体验关闭时、Kimi 券用完、混元资源包过期后、llm7、硅基流动）都必须**主动配置熔断**，否则「一直在线」会变成「一直扣钱」。
3. **「能操控本机」= 需要可靠的 function calling + 长上下文**。这排除了 Groq free plan（**TPM 只有 8K**）、Cloudflare Workers AI（10,000 neurons 一天只够 1～2 次长请求）、Cerebras（5 RPM）。

### 6.2 网关之外该备哪几个直连后端

**答案：只备 3 个，按「国内优先、国际兜底」排列。**

| 优先级 | 后端 | 角色 | 选它的理由 | 必须做的配置 |
|---|---|---|---|---|
| **备一** | **智谱 `glm-4.7-flash`**<br>`https://open.bigmodel.cn/api/paas/v4` | **主力直连（网关失效时接管）** | 唯一「永久免费 + 不限量 + 官方定位为长期产品」的国内档；支持 Function Calling（操控本机刚需）、思考模式、200K 上下文、MCP | base_url **带尾斜杠**；**串行化调用（并发 1）**；超时重试要配退避；**禁用** `glm-4.5-flash`（已下线，会被静默路由） |
| **备二** | **ModelScope**<br>`https://api-inference.modelscope.cn/v1`<br>model `Qwen/Qwen3.5-35B-A3B` | **第二梯队（按天重置，不会断供）** | **2000 次/天自动重置**，不需充值；131K 上下文；阿里系模型更新最快 | 需一次实名 + 绑阿里云；**读 `modelscope-ratelimit-requests-remaining` 响应头做自适应降级**；避开 R1-0528 这类只有 100 次/天的大模型 |

| 备四（可选） | **讯飞星火 Spark Lite** | 「要联网搜索」时用 | 唯一「免费 + 带联网」的档 | 鉴权是「APIKey:APISecret」冒号串；**不支持 FunctionCall**，只能当「搜索子代理」不能当主脑 |

**明确不推荐纳入常驻链路的**：

- **llm7** —— 已无免费额度，model 名也已过期（§1.4）。
- **OpenRouter `:free`** —— 50 RPD，做不了常驻；适合做「一次性大批量生成」时的补充。
- **Gemini 免费层** —— 数据用于改进产品，与「本地私密人格」定位冲突。
- **Cerebras** —— 需绑卡 + 5 RPM。

- **百炼 / 混元 / Kimi / 豆包** —— 都是一次性额度，适合批处理不适合常驻。

```
   └─ 网关挂 / 连续 2 次失败 → 2) 智谱 glm-4.7-flash（串行，1 并发）
                              └─ 智谱 429 或超时 → 3) ModelScope Qwen/Qwen3.5-35B-A3B
                                                  └─ 仍失败 → 4) pollinations（30s 1 次，只回一句话）
                                                          └─ 全挂 → 5) 本地 llama.cpp（模板化兜底）
```

**跨后端切换时必须注意的三件事**（这些是「同一套代码跑不同后端」最容易翻车的地方）：

1. **思考字段名不统一**：Ollama 官方文档用 `message.reasoning`；OpenAI 兼容侧（含硅基流动、智谱）用 `reasoning_content`；本项目 `ai_backends.py` 若要消费思考内容需两处都取。
2. **`response_format` / `tools` 支持度不一致**：本地 llama.cpp 支持 `/v1/chat/completions` 但工具调用质量随模型而异；讯飞 Lite 完全不支持 FunctionCall。**降级链要按「能力递减」排，不能随机跳。**
3. **限流语义不同**：智谱是并发 1（要排队）、OpenRouter 是 50 RPD（要跨天）、pollinations 是 30 秒 1 次（要延时）。**统一的退避策略必须能区分「并发满」「日额度满」「秒级限速」三种错误**——它们需要三种完全不同的处理。

### 6.4 「操控本机」这条链的特殊要求

- **必须把 Function Calling 的可用性作为选型第一优先级**，其次才是上下文长度。
- 智谱 `glm-4.7-flash` 支持 Function Calling + 结构化输出 + MCP，**是国内档里唯一全绿的**。
- ModelScope 上有 Function Calling 能力的模型需逐个到模型页确认（官方未在 limits 页列能力矩阵）。
- 本地 214M 级小模型**可以做工具参数抽取**，但**不要指望它做多轮规划**。

## 7. 与本项目实现相关的风险点

> 只列**本次调研新发现**的；报告一已列的 `persona_card.py` 风险不重复。

| # | 风险 | 证据 | 影响 | 建议（不改代码，仅记录） |
|---|---|---|---|---|
| **B1** | **llm7 的 model 硬编码已失效** | `fleet/ai_backends.py:97` 写死 `"model": "gpt-4o-mini"`；2026-10-21 实测 llm7 的 70 个模型里**没有 `gpt-4o-mini`** | 一旦有人配了 `FLEET_LLM7_TOKEN`，请求必然 4xx，且报错信息会指向「key 无效」而非「model 名过期」，排查成本高 | 改为从 `/models` 动态取（`ai_backends.py` 已有 `pick_model` 逻辑，但 llm7 分支写死了 model）；或直接下线 llm7 分支 |
| **B2** | **llm7 已不是免费后端，注释与现实相反** | `ai_backends.py:91` 注释「llm7：免费但要 token（每天 10 万 token）」；实测 **70 个模型零 free 档、61 个 usage_based_only、匿名对话 429** | 会误导后续维护者以为 llm7 是免费档而优先选它 | 修正注释；把它明确归类为「付费兜底」 |
| **B3** | **pollinations 匿名层有全局结果缓存** | 官方 APIDOCS.md：「The same URL returns the same result, **to anyone with the URL**」 | 若把「她」的状态化内容拼进 prompt 并命中缓存，**可能把同一段回复返回给不同用户**；且人格对话内容会被公开缓存 | 只用 pollinations 做无状态/低敏兜底；或改用 `enter.pollinations.ai` 的带 key 通道 |
| **B4** | **pollinations 限流 30 秒 1 次，会直接卡死对话节奏** | 官方 APIDOCS.md Limits 表 | 若被误设为默认后端，用户体感是「她不回话」而不是「被限流」 | 在后端健康检查里显式识别 402 + `Retry-After`；把「每 IP 最小间隔」做成后端元数据 |
| **B5** | **本地网关 51 条模型里多为 `:free` 别名，稳定性不可控** | 实测 `/v1/models`：17 个唯一 id 大量是 `kilo-auto/free`、`openrouter/free` 这类**指向 OpenRouter 免费池的别名** | 这些别名的真实限流 = OpenRouter 的 50 RPD，**网关表面上有 17 个模型，实际可用配额可能只有一份** | 后端健康检查要按**上游**限流，不要按模型条数判断容量；建议为网关配置多上游 |
| **B6** | **「免费后端」缺少统一的熔断** | 现有 `ai_backends.py` 逻辑里未见「按错误类型区分限额耗尽 vs 服务不可用」的分支 | 百炼/豆包/Kimi/硅基流动这类「用完转按量计费」的后端，若接进来，**在无人值守的「一直在线」场景下会静默扣费** | 若后续接入任何按量后付费的平台，必须实现：额度耗尽 → 停止该后端 + 告警，**绝不自动转下一个付费后端** |
| **B7** | **本机未安装任何本地推理运行时** | 实测 `127.0.0.1:11434` / `127.0.0.1:1234` 均无响应；`which ollama llama-server lms` 全空 | 「离线兜底」这条链路目前**不存在**，是纸面能力 | 若要保留这条兜底，需要先安装 + 预拉一个小模型（214M 级足够做工具参数抽取） |
| **B8** | **本机 16GB 单通道 + 无独显，本地推理不能承担主对话** | 实测 Qwen3-4B Q4_K_M 仅 **3.86 tok/s**（300 token 需 ~78 秒） | 若有人提议「用本地模型替代付费 API 省钱」，实测数据不支持 | 明确写进设计文档：本地只做分类/抽取/兜底 |
| **B9** | **思考字段名跨后端不统一** | Ollama 官方文档用 `message.reasoning`；OpenAI 兼容侧用 `reasoning_content` | 解析器只认一个字段名时，切换后端会导致「思考内容消失」或解析报错 | 解析时同时兼容两个 key |
| **B10** | **Gemini 免费层「内容用于改进产品」的条款与本项目定位冲突** | 官方定价页明示免费层数据会被用于改进产品 | 「她」的人设、历史、情绪状态属高敏数据 | 如确需接入，必须在产品层做**上下文脱敏**（不送人设全文、不送历史原文），并在文档里写明 |
| **B11** | **ModelScope 官方定位是「非商业、非营利」** | 官方 limits 页原文「API-Inference itself is a non-commercial, non-profit product」 | 本项目若未来商业化，用它当后端有条款风险 | 个人自用无妨；若商业化必须换付费源 |
| **B12** | **国产平台的 base_url 尾斜杠 / 鉴权格式差异易踩坑** | 智谱需 `https://open.bigmodel.cn/api/paas/v4/`（带尾斜杠）；讯飞用「APIKey:APISecret」冒号串而非单独 hex Key | 同一套 `base_url + key` 配置在换平台时会静默失败或 401 | 后端配置增加「格式校验」：尾斜杠归一、key 格式提示 |
| **B13** | **旧 model 名会被静默路由，行为漂移** | 智谱 `glm-4.5-flash` → 自动路由到 `glm-4.7-flash`；DeepSeek `deepseek-v4-flash` → 路由到 V4.1-Flash-1017 | **不报错，但模型已换**——人格表现会无声漂移，难以定位 | 后端配置里只允许「当前有效 model 名」；启动时校验一次 |
