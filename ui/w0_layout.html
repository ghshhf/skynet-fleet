设备编队人格: 大肥鱼 v3已取消 43m31s

先说结论：电视去广告不需要 root，走 WiFi 局域网 ADB 就够，而且完全可逆。

  • 核心命令是 pm disable-user——只在当前用户层停用组件，系统分区原封不动。
  • 改完想还原，跑一键恢复脚本，把被停用的包 pm enable 回来即可。
  • 前提是电视开着「网络 ADB 调试」，电脑和电视在同一个 Wi-Fi 下。

不过动手前我得先确认两件事：你的电视是什么牌子型号（不同品牌开调试的路径不一样），以及那台电视能不能被无线 ADB 连上——三星和 LG 是不支持的，因为底层不是安卓。

小米的话，在电视上按这个顺序开：

  • 设置 → 关于 → 连点「版本号」7 次，进入开发者模式。
  • 返回设置 → 系统 → 开发者选项 → 打开 USB 调试 和 网络调试。
  • 注意小米国内特供固件有时会把「网络调试」单独锁掉，如果菜单里没有这一项，就要走别的路子。

开好之后我这边扫网段找它，找到会先问你一句再动手——动电视是要过闸门的。
