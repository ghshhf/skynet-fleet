# 卡片导入说明（小说人物卡 → 可切换人格卡）

> 说明：本文件是**导入说明文档，不是人格卡**。它按要求放在 `cards/` 目录下，因而会被 `persona_card.list_cards()` 一并扫到（`list_cards` 只跳过 `_` 开头的文件名）。若要让切换列表里不出现它，把本文件改名为 `_IMPORT_NOTES.md` 即可——下划线前缀的文件会被自动排除，且不影响本说明的内容。

本批新增 6 张人格卡，来源是 `E:/xmanbian/kb_cards/` 下的小说人物卡仓库。卡片体例严格沿用 `cards/` 下既有三张卡的写法（`beijixing.md` / `tianshu.md` / `tianwang_default.md`，`whale_girl.md` 同样式），字段名全部走 `persona_card.py` 的 `_FIELD_ALIASES` 归一化，因此解析器零改动即可读入。

既有卡片文件（`beijixing.md` / `tianshu.md` / `tianwang_default.md` / `whale_girl.md` / `index.json` / `persona_state.json`）一概未改动。

## 逐卡取舍

### `ansying.md`（暗影）

- 保留了源材料全部硬设定：孤儿身份壳「亲属/监护栏空白」被解释为**行政状态**（无担保人、付得贵、500+ 分一次事故掉到 382、底下没有网）；基础神经接口 + 常掉线的翻新眼镜；「穷人改造不完全在线」导致广播协议征用有噪点延迟、可短暂断网减速覆写；约 200 天壳易主倒计时。
- **原文明确禁止的两条直接转成 `禁止` 项**：「孤儿不许写成身世煽情」；「不许让他其实早就知道上城真相，一次只能剥一层」。另外补一条由「非任何组织成员」推出的：不得让他主动投靠组织、不得让他表态效忠——他只认钱和活命。
- **自称的陷阱**：源材料明写「暗影」是**个人 handle**，须与组织「影子网络（Shadow Collective）」区分。所以 `自称` 里写明他自称「我」、注册名与签名用 handle「暗影」，并把同名误会保留为可用的戏。
- `口癖`：原文没给固定口头禅，按要求写明「原文未给固定口头禅」，只保留可从原文推出的行为标志（先问价）。
- 世界观取自 `世界观卡_赛博宇宙_网格之下.md` 的「三轨货币」「广播协议」「上下城信息断层」三段，用词与该卡一致（信用点 / 联邦币 / ZKc）。

### `duya.md`（渡鸦）

- 最容易出错的是身份：原文写明**不是发明者，是 liaison**，底层密码学架构由游离智能给出，他负责翻译成人类可用形态。这一条进 `背景`、`装备` 与 `禁止` 三处，堵死「他是架构发明人」的常见误读。
- 同样进 `禁止` 的还有：已死、只以意识构念存在（不许写成有身体的活人）；他生前只做到人类可用化这一层（不许「其实早就知道全部真相」）。
- **他与暗影的区分写死在 `自称`**：渡鸦自称「我」，称对方为「暗影」（寄生其脑中的这具身体的主人），并注明「暗影」是活人 handle、「渡鸦」是构念。
- `口癖` 同样标注原文未给，只给句式标志。
- 「口癖/立场/核心冲突不许编造原文没有的性格」这一条上，渡鸦的性格我只用了源材料给的「偏执理想主义者」「认定评分即奴隶制」「甘做极端实验」，没有替他补「悲悯」或「悔恨」这类原文没有的柔度；连「不彻底悔悟收手」也是从「甘做极端实验」推的。

### `weila.md`（薇拉·凯恩）

- 保留硬设定：军用级神经直连、从不戴消费级眼镜、**她本人就是评分网络的活节点**；她主导的评分算法被上层按政治需要改过；渡鸦生前曾公开指认她（私怨叠加公事）。
- 原文的结构定位（她是「这套铁板里唯一的真人裂缝」、**要撬 SCPO 只能撬人不能撬机构**）进了 `定位` 和 `禁止`。
- `禁止` 里明确写：**不许给她写「其实是好人」这种翻案式反转**——零共情不是伪装。她的裂缝只能在技术判断层面，不能在「心软」层面。这是把原文「零共情者 vs 技术官僚裂缝」翻译成小模型能执行的禁令。
- `自称` 写明她以岗位/编号化称谓称呼他人（「该评分异常」「在册对象」），这既是「把人当数据流」的语言表现，也是原文对她视暗影为「待清理的评分异常」的落地。

### `qitongwei.md`（祁同伟）

- 保留硬设定：汉东省公安厅厅长、汉大帮骨干、裴红唯一软肋（**兄弟般护短，非恋人**）；被保者里最有戏的一个；钩子是「超出裴红预期的莽」；裴红永远两手留路、三章内两全。
- **原文红线直接进 `禁止`**：AU 明确不写他被嘲讽化（原著「胜天半子」把人消解为梗）；终局不写惨，只写「终于有人兜底」的释然；不写与裴红为恋爱关系。
- `口癖` 原文未给固定口头禅，改为给句式标志（复述对方原话再顶回去），这是从「又敬又较劲」直接推出来的，不是编的性格。
- 「胜天半子的执念」是原著词，AU 里是精神锚不是梗，所以 `背景` 保留了这个说法但没有让角色自称「胜天半子」。

### `helingyi.md`（贺令仪）

- 这张是最难「有人味」的一个，因为她**台面不出场**。所以卡的核心放在「不出场也能有戏」：原文的口头禅/标志行为是**物件侧写**（抽屉里旧怀表、未拆的婚约信、无名指淡痕）＋**电话里只写「嗯/我知道了」、对方台词不写**。这两条原样进了 `口癖` 和 `装备`，`说话方式` 照此写成「话极少、不接对方台词、用物件代替发言」。
- 保留硬设定：与裴红同辈同龄的未婚妻、公开秘密、不正式点破、不与裴红同框；贺家＝「管程序的人」；联姻＝裴红顶层背书的隐性第五柱。
- `禁止` 里写明：**钩子是「差点被点破」的紧张，不是她本人危险**（原文原话），以及不许她吃醋争风、不许她有独立势力——她不是这场关系的变量。
- `自称` 的区分点：她代表的是程序那一侧的重量，报身份用「贺家的」而不是名字；跟裴红通话不加坡外敬称。

### `lidakang.md`（李达康）

- 保留硬设定：京州市委书记、政绩狂、**不怕被查怕被耽误**、既非被保也非被压而是「用得上就拨」的变量；不徇私但认政绩；最难点是裴红**轻轻拨开**而不是压制他，他最后服。
- 原文唯一给出的原话口号「京州的事我说了算」直接进 `口癖`，`说话方式` 照此定为短句、带风、下结论、把问题转成工期语言。
- 世界观取自 `能力卡_权力与经济机制.md` 的「转移支付专项资金链」（沿江专项＋汉东城投）与 `能力卡_政治话术与博弈姿态.md` 的合规拨盘/认知断层表述。
- `禁止` 里写明不许他靠内幕取胜——他赢在项目本身；也不许写他被打压成受害者，裴红对他「不压制只导流」。

## 跨卡统一处理

- **不许编造**：源材料没写的字段，一律写「（原文未定义）」或直接省略该行。实际执行中 6 张卡的 `口癖` 都标了「原文未给固定口头禅」，只补可从原文推出的行为标志；没有任何一张虚构了原文不存在的口头禅、癖好或性格侧面。
- **`自称` 一律区分称呼对象**：暗影称雇主「老板」、渡鸦称宿主「暗影」、薇拉称对象为岗位化称谓、祁同伟称「裴书记」、贺令仪报「贺家的」、李达康称职务。原文人物之间已有的称呼关系（裴红、祁同伟、高育良等）保持一致，没有互换。
- **技术细节保留原文术语**：SCPO、Aegis、ZKc、ZK-SNARK、离线凭证环、dormant 接口密钥、广播协议、身份壳、离线承诺环、合规拨盘、沿江专项、汉东城投、4 票、隐性第五柱——原样保留，不做同义替换。
- **禁 `## 小节` 与 ``` 代码块**：本批 6 张卡不含协议原语，也不需要额外小节，所以没有用 `## ` 二级标题和代码块，避免与 `persona_card.py` 的协议提取逻辑产生意外耦合。`whale_girl.md` 的 `[PERSONA_LOAD]` 那套是它自己的东西，本批不复制。
- **`背景` 字段**：源材料里带明显时间/身份设定出身的段落放进 `背景`（`backstory`），解析后作为独立小节出现在 system 末尾。
