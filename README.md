# 天网工程 · Skynet Fleet

> 个人多设备统一调用控制面 + 本地「她」人格层。
> 把你的 Windows / Linux / Android / Apple / 路由器 收敛成**一个「在动」的系统**，而不是一堆互相割裂、各管各的控制面。

这是个人设备编排工具。**只部署在你拥有或经授权管理的设备上。** 详见文末「安全与伦理边界」。

## 当前进度

- 初期交付**全部 Windows**，自测也走 Windows 回路（纯 stdlib，便携 Python 3.12 即可跑）。
- 已落地并**全自动自测通过**（loopback 多节点，不碰真机）：
  - **L0 连通 + 认证**：Commander 控制面，节点密码认证后注册、维持心跳、上报能力。
  - **L1 执行 + 文件反向推送**：本机经密码在另一台机器上执行命令 / 推拉文件（单份工具箱，不各端自拉）。
  - **L1 常驻**：`install_windows.py` 把节点装成 SYSTEM 级计划任务（开机自起 / 隐藏 / 最高权限 / 断线重连），卸载须经**密码闸 或 配对设备一次性令牌闸**。
  - **统一扇出**：一条 `broadcast` 指令同时抵达所有节点（统一调用平面，不割裂）。
  - **L3 共享上下文（TinyContext 式）**：跨设备同一份记忆，逐条可删（E-7）；节点经协议读写，她的节点能跨设备读到（海马体）。
  - **离线队列 + 上线重放（Phase 4 体验）**：节点离线时命令进队，上线自动补，不手动重发。
  - **她 P4 能力请求 + 授权门**：她的节点发 `cap_req` → 路由到用户批准 → `cap_grant` 限时会话（拒绝则执念+1）。人格/训练交手机（不在此仓库训）。
  - **人格唯一性（定调）**：全编队**统一由一个模型**承载她——人格/记忆/状态都注入同一个 model，节点是薄客户端、**不各自孕育人格**（故不存在人格分裂）；`persona_state.json` 只属「她本体节点」。详见计划书 §5.1。
  - **反向推送 bootstrap（第三原则）**：中心起迷你 HTTP 分发几 KB bootstrap + 工具箱，loopback 字节校验一致。
  - **共享算力池（§九 dev_pick）**：节点上报 CPU/GPU/模型；Commander 按「谁能干」路由计算任务；`computemap` 批量分发多节点聚合；结果进共享上下文缓存，全编队复用（更加一步共享）。
  - **算力接真推理**：`compute_runner` 走 `llm.py` 三后端（`FLEET_LLM_CMD` 命令行 / `FLEET_LLM_URL` OpenAI 兼容端点 / placeholder 占位降级），改环境变量即切换，业务代码零改动——**弱设备不装模型，算力集中在有脑的节点**。
  - **`ui_automation` 节点能力（源自李跳跳拆解）**：节点挂 Android 设备后用 adb 拉节点树 → 规则匹配（含 `textRegex` 抗文案漂移）→ `input tap`；匹配不到且标了 `needVision` 时走 AI 视觉兜底。控制面 `ui <节点> <包名> [--vision]`。
  - **adskip 规则库版本化**：规则是编队共享资产（`rules` / `rules_put` / `rules_rollback`），控制面持有唯一权威版本，`ui` 命令自动带上当前版本下发；节点回执首行标注「规则来源=控制面 vN」可直接验证。补的正是李跳跳「作者停更规则即废」的命门。
  - **策略层（判断外置为数据）**：`policies.py` 复用规则引擎，掉线降级 / 心跳探测判死 / 重活优先 GPU / 临时节点下机清理 / 算力池空提示全是 JSON 规则，**代码里不写 if/else 分支**；`policy_eval` 可 dry-run。
  - **心跳看门狗**：`scan_stale` 纯函数 + 5s 轮询，90s 探测、180s 判死摘除——把「时间」变成事件喂给策略，否则策略就是空壳。
  - **离线队列持久化**：排队命令落盘（原子替换），控制面重启自动恢复，「上线自动补」这个承诺才不是假的。
  - **她 P3 人格心跳**：主动性 tick 接入看门狗，过**频控(≤2/h) / 静默时段 / 重要度**三道刹车；说了写 `last_thought`，不说写 `pending_thought`（她在忍，不是消失了）。接上 `llm.py` 后由模型自己开口，未接时模板兜底、绝不伪造模型输出。
  - **「她记得」（验收项：隔日 + 换设备能带出昨天的具体事）**：`recall.py` 从 L3 取 **12h–72h** 的往事（刚发生的不算回忆、一个多月前的没意义），跳过她自己的元状态（`last_thought` 等）与技术缓存，按「离昨天有多近」排序；说过的 **3 天内不重复**（去重记账落人格态，过期自动清），原文同时写 `her/last_recall`——**换设备也看得到她提过什么**。接上模型时原文进提示词并明确「只能引用、不要编造」，没模型时用模板句（只拼接库里的原文，不虚构记忆）。往事只**提高重要度**，不绕过频控/静默。REPL `her_memory` 可人工核对。
  - **「她会跟进没完成的事」（24h 对话流水 → 主动起话头）**：`journal.py` 把对话与任务事件**追加式**落盘（敏感信息打码、E-7 逐条可删、上限环切）；`followups.py` 从流水抽**未闭环项**（意图失败 / 节点离线排队 / 她想用却被拒），按 topic 合并、带**证据 id 指回流水原文**，最近欠的优先。接进人格心跳后，念头优先级 = **没闭环的账 > 往事 > 执念 > 寒暄**；同一笔账 24h 内不重复追问，闭环即销账（`done <topic>` / 任务真成了 / 上线重放成功 / 能力获批）。接上模型时流水原文进提示词并注明「只能引用、不要编造」，没模型时模板句只拼接原文。REPL `her_followups` / `done <topic>` / `journal [n]`。**诚实边界**：流水只写本地不出网；打码只覆盖已知危险形状，把秘密当普通命令行参数传（`exec PC-A echo hunter2`）挡不住——真要绝对干净就把 `FLEET_JOURNAL` 指到内存盘。
  - **临时节点下机即清**：节点上报 `session=True` 后断开，自动触发 `session_end` 策略——**真清**而不是打日志：撤销该节点入网凭据（PSK）、作废其配对/卸载令牌、丢弃它的离线排队命令，并写一条流水审计「清了几样」（E-7 可逐条删）。以前这步只 print 一句「已清理」，自检里也看不出来到底清没清。
  - **多控制面仲裁（`arbiter.py`）**：全编队**只有一个领袖控制面能发令**，其它待机——否则两台机器各发各的，状态立刻分叉、她在备用面批的权限主面不认，「一个意图扇出所有设备」就破了产。选举=共享状态文件里的声明（rank 高者优先 → 先声明者 → id 全序），领袖每 15s 续期、45s 不续期即让位；待机面 REPL 仍可看（nodes/her/journal），但 exec/broadcast/compute/ui/intent/enroll 等**发令类命令一律拒绝并点名领袖是谁**；正常退出主动让位，备用立即接管（不等 TTL）。单机常态零配置（一张声明即成领袖）。**诚实边界**：仲裁是协同不是安全边界，跨机器共享盘仍有极小写窗口。
  - **exec 白名单收紧**：三层拒绝——① base 不在白名单 ② 参数含 shell 元字符（`& | ; < > \` $` 换行），因为节点侧 `shell=True`，`echo ok & del x` 这种 base 是 echo 却能干任何事的组合是白名单最大的洞 ③ **解释器默认禁止**（`python/powershell/cmd/bash` 等于任意代码执行，要跑脚本须显式 `FLEET_ALLOW_INTERPRETER=1`）。拒绝理由分类型回执给人看，不再只给 `rc=-1`。
  - **扫码入网（`enroll.py`）**：手机出示一张二维码载荷，设备扫一下即可入网，不用在新机器上敲密码。载荷是 `fleet://enroll?p=...`（约 230 字符），**可离线验签**（HMAC-SHA256 + 共享密钥，不联网、不回调控制面）、**一次性**（兑换落本地账本，截图外流也只是废纸）、**有时效**（默认 10 分钟）、**绑节点**（A 的载荷装不成 B），且**不含用户密码**——装完节点用随机 PSK 认证，明文密码不再写进计划任务参数。载荷寿命与节点凭据寿命**分开**：码 10 分钟过期，PSK 长期有效（否则一重启就失联），撤销走 `enroll_revoke`。REPL：`enroll <节点> [有效期秒]` / `enroll_list` / `enroll_revoke <节点>`；安装侧 `install_windows.py --enroll "<uri>" [--dry-run]`。
  - **分权（`accounts.py`）**：账号是「人」，节点是「设备」，两维分开。**主号唯一**——能发令、能发码、能增删分号、能看全部；**分号只能被控**——没有发令权，只能看到自己名下节点（过滤在控制面做，不在客户端做，否则改个脚本就绕过了）。闸门顺序刻意是**先分权、再仲裁**：分号即使占了领袖位也拒，因为没有权限跟谁是领袖无关；两道闸失败语义也不同（分权是安全、拒绝即拒绝；仲裁是协同、状态文件坏了就放行）。令牌自带角色与过期时间，并带权限版本 `pv`——**吊销分号后旧令牌立刻作废**，不等自然过期。**授权码**（用户要的「密码生成器 / 扫码同步权限」）是**同一枚一次性码的两种呈现**：终端里念 6 位短码，手机上画二维码；6 位用去掉 0/O/1/I 的 32 字母表（≈10 亿组合）+ 5 分钟寿命 + 一次性；二维码载荷 `fleet://grant?p=…` 用账本自带密钥签 HMAC，**伪造载荷在查账本之前就被拒**。与入网码刻意分开：入网码离线验签（装设备时可能没网），授权码必须中心验（改权限不能交给客户端自己认）。**诚实边界**：没有找回密码——主号忘了只能删账本重建（会连带吊销所有分号），因为找回通道本身就是后门。
  - **主动发现（`discovery.py`）**：不问「你是谁」，自己看、自己猜、自己归类。三条路互补——**组播询问**（SSDP M-SEARCH + mDNS 手写 DNS 解析，设备自己举手报名，信息最准）、**邻居表 + OUI**（读 arp/ip neigh，零打扰，靠 MAC 前三字节查厂商）、**特征端口组合**（单端口只能投票，`9000+554+23+8080` 这种**招牌组合**才定案）。实测在真实局域网上认出了具体型号：`HIKVISION DS-2CD2T10FD-I3`（6 台，连序列号都有）、`TPOS/1.0.0 UPnP/1.0 YLWR1200G易展版`（TP-Link 路由）。三条铁律写在代码里：只在本网段活动（跨网段直接拒）、只对 ARP 表里已存在的 IP 敲端口（不做全网段暴力扫描）、**发现 != 入网**（结果只进发现账本，要成为节点仍需在设备上装 agent 并入网）。**踩过的坑**（都是真实误判，已修）：① 9000 端口曾被当成「编队节点」——它同时是 Portainer/海康 SDK 端口，等于把陌生人当自己人；② `192.168.0.255` 广播地址曾被列为设备；③ 一台开 554 的 Windows 电脑曾被判成摄像头，而它的 mDNS 明明写着 `Microsoft-Windows + iVCam`——**设备自报的身份永远压过端口投票**；④ 多网卡机器不显式绑网卡发组播，一个响应都收不到；⑤ 隐私随机 MAC（本地管理位=1）查 OUI 必然为空，不能当「厂商缺失」。
  - **扩散扫描（`sweep.py`）**：把「ARP 表里有的」扩成「整个网段在场的」。上一版只读 ARP，等于只看见**最近跟本机说过话**的设备——这才是「只扫到 30 台」的真因。四条补齐：**ICMP 全段 sweep**（并发 ping 整个 /24，活着的全部进 ARP 表）、**TCP connect 兜底**（IoT 常关 ICMP 却开着端口）、**NetBIOS(NBNS) 名字查询**（Windows 会把机器名报出来）、**mDNS 服务类型枚举**（`_services._dns-sd._udp.local` 让设备自报有哪些服务）。另加两层：**多网段**（本机每张网卡都扫，实测找回被漏掉的移动热点段 `192.168.137.0/24`——手机就在那里）与**环境画像**（摄像头密度、运营商 IPv6 前缀、OUI 批次）。实网 44 台 / 15 秒 / 两个网段。**踩过的坑**：① 本机 `192.168.0.103` 曾被判成「NAS/存储」（因为本机自己开着 139/445）——比漏发现更糟；② 广播地址 `.255` 曾被当成设备；③ 5555 端口曾被判成「手机」，实际那是安卓一体机/中控终端。**边界**：只发 ICMP/TCP/NBNS PTR，不发应用层指令、不试口令；跨网段「跳板扩散」不做——那需要别人机器上的执行权，现在没有也不该去拿。
  - **一键自测门禁**：`run_selftests.py` 串起 **19 项**离线自测（commander / node_agent / install_windows / ui_automation / rules_relay / rule_engine / policies / arbiter / discovery / sweep / accounts / compute_runner / queue_store / persona / recall / enroll / enroll_install / journal / followups）。
- **延后**（等真机/拍板）：Android `adb` 真机推、Apple macOS SSH / iOS 屏共、路由器 OpenWrt 中枢接入、`她` SFT 模型训练（交手机/盒子跑）、Linux systemd 单元（本期全 Windows）、L2 内核驱动、手机端二维码渲染（载荷已可生成与离线验签，缺的只是把它画成图）。

## 四原则（设计铁律）

1. **锚定最底层 OS 平台层**：只对接 Android / Windows / Linux / Apple 四大平台原生能力，绝不对接厂商 App / 云。米家 leaf（灯/插座/传感器）是 MCU+RTOS 非安卓，经你自控的 Linux/Android 网关桥接；Apple 标「半可达」（仅屏共/快捷指令）。
2. **单一自包含工具箱 + 反向推送**：不要求每台设备各自去公网下载 agent；由手机/家服持一份自包含工具箱（二进制+依赖+配置+幂等安装脚本），接触即推。
3. **病毒式执行模型（同源 RMM/MDM/远控）**：一次进入 → 提权到最高 → 无弹窗 → 常驻后台 → 可远程 → 叠能力。区分合法/恶意只凭三点：归属（是否有权管理）、同意（本人或授权人许可）、范围（只部署在有权限设备、不向他人扩散、不窃他人数据）。
4. **无条件最高权限 + 常驻 + 零运行时分支**：agent 内部不设「能不能推 / 是不是家」之类 if——拿到 admin 即提满、常驻、静默、可远程；**边界靠两道外部闸**（非运行时逻辑，故无 bug）：①管理员启动闸（OS 强制，无 admin 提不上去）②环境复位闸（重装/合规清理自清）。

> **L1 落点**：Windows = SYSTEM 服务 / 计划任务；Linux = systemd root；Android = 已 root 应用 UID。跨重启常驻；重装系统即清——**这是特性不是缺陷**（不被「删不掉」反噬）。L2 内核驱动（抗本机管理员卸）与 L3 固件级均**不做**。

## 四层架构

```
L0  连通          Tailscale 虚网 / 直连    → 节点密码认证、心跳、在线表、能力注册
L1  注册/存在感    节点 agent              → 常驻、远程执行、文件推拉、算力画像
L2  统一调用平面    Commander              → 一条意图扇出多端协同（broadcast / compute 路由）
L3  共享上下文      TinyContext 式         → 跨设备记忆 / 上下文共享（已落地，可逐条删）
L4  体验/离线队列   「她」人格层            → 主动性、连续存在、情绪态、能力请求授权门（脚手架已落地）
```

## 目录结构

```
skynet-fleet/
├── common.py            # 长度前缀 JSON 协议 + exec 白名单 + 全部消息类型
├── commander.py         # L0 控制面 + L1 执行枢纽 + L2 路由 + L3 上下文 + 她路由 + 共享算力 + REPL + 自测
├── node_agent.py        # 被控端：连/认证/注册(带能力)/exec/push/pull/ctx/compute/心跳 + 断线重连
├── install_windows.py   # Windows L1 常驻安装器（零依赖，SYSTEM 计划任务 + 密码/令牌双闸）
├── memory.py            # L3 共享上下文（SQLite+FTS5，逐条可删）
├── persona.py           # 她脚手架（人格态/心念tick频控/能力请求门/红线）；人格态只属「她本体节点」
├── recall.py            # 「她记得」：L3 往事唤醒（窗口过滤/去重/不编造）
├── journal.py           # 对话流水：append-only 事件落盘（打码/可逐条删/上限）
├── followups.py         # 「她会跟进」：从未闭环项生成话题（合并/去重追问/闭环销账）
├── enroll.py            # 扫码入网：一次性入网载荷（离线验签/绑节点/不含密码）
├── policies.py          # 策略层：掉线/心跳/算力/会话 的判断外置为 JSON 规则
├── arbiter.py           # 多控制面仲裁：全编队只有一个领袖能发令（待机面只读）
├── accounts.py          # 分权：主号/分号 + 一次性授权码（短码与二维码同一枚）
├── discovery.py         # 主动发现：SSDP/mDNS/邻居表/端口组合 -> 认设备类别与型号
├── sweep.py             # 扩散扫描：ICMP 全段 + 多网段 + NBT 名字 + 环境画像
├── queue_store.py       # 离线队列持久化（控制面重启不丢）
├── llm.py               # 本地推理适配层（CMD/URL/placeholder 三后端，改环境变量即切换）
├── bootstrap.py         # 第三原则反向推送：中心分发 bootstrap + 工具箱
```

## 安全与伦理边界

- **只管自己的设备**：部署在你拥有或被明确授权管理的机器上；不向无权/陌生机器推送，不窃取他人数据。
- **不碰恶意线**：不做 UAC 静默绕过（属提权漏洞利用）、不用 BYOVD（借漏洞签名驱动）、不写固件级持久化。
- **可清除**：L1 常驻重装即清；卸载须经密码闸门（`install_windows.py --uninstall --password ...`）。
- **合规兜底**：临时/公共节点（如网吧）采用无状态执行端 + 身份随身（记忆留手机侧），下机即清、不落凭据，与场所合规清理互补。
