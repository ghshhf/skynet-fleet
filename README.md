# 天网工程 · Skynet Fleet

> 个人多设备统一调用控制面 + 本地「她」人格层。
> 把你的 Windows / Linux / Android / Apple / 路由器 收敛成**一个「在动」的系统**，而不是一堆互相割裂、各管各的控制面。

  - **临时节点下机即清**：节点上报 `session=True` 后断开，自动触发 `session_end` 策略——**真清**而不是打日志：撤销该节点入网凭据（PSK）、作废其配对/卸载令牌、丢弃它的离线排队命令，并写一条流水审计「清了几样」（E-7 可逐条删）。以前这步只 print 一句「已清理」，自检里也看不出来到底清没清。
  - **多控制面仲裁（`arbiter.py`）**：全编队**只有一个领袖控制面能发令**，其它待机——否则两台机器各发各的，状态立刻分叉、她在备用面批的权限主面不认，「一个意图扇出所有设备」就破了产。选举=共享状态文件里的声明（rank 高者优先 → 先声明者 → id 全序），领袖每 15s 续期、45s 不续期即让位；待机面 REPL 仍可看（nodes/her/journal），但 exec/broadcast/compute/ui/intent/enroll 等**发令类命令一律拒绝并点名领袖是谁**；正常退出主动让位，备用立即接管（不等 TTL）。单机常态零配置（一张声明即成领袖）。**诚实边界**：仲裁是协同不是安全边界，跨机器共享盘仍有极小写窗口。
  - **exec 白名单收紧**：三层拒绝——① base 不在白名单 ② 参数含 shell 元字符（`& | ; < > \` $` 换行），因为节点侧 `shell=True`，`echo ok & del x` 这种 base 是 echo 却能干任何事的组合是白名单最大的洞 ③ **解释器默认禁止**（`python/powershell/cmd/bash` 等于任意代码执行，要跑脚本须显式 `FLEET_ALLOW_INTERPRETER=1`）。拒绝理由分类型回执给人看，不再只给 `rc=-1`。
  - **扫码入网（`enroll.py`）**：手机出示一张二维码载荷，设备扫一下即可入网，不用在新机器上敲密码。载荷是 `fleet://enroll?p=...`（约 230 字符），**可离线验签**（HMAC-SHA256 + 共享密钥，不联网、不回调控制面）、**一次性**（兑换落本地账本，截图外流也只是废纸）、**有时效**（默认 10 分钟）、**绑节点**（A 的载荷装不成 B），且**不含用户密码**——装完节点用随机 PSK 认证，明文密码不再写进计划任务参数。载荷寿命与节点凭据寿命**分开**：码 10 分钟过期，PSK 长期有效（否则一重启就失联），撤销走 `enroll_revoke`。REPL：`enroll <节点> [有效期秒]` / `enroll_list` / `enroll_revoke <节点>`；安装侧 `install_windows.py --enroll "<uri>" [--dry-run]`。
  - **分权（`accounts.py`）**：账号是「人」，节点是「设备」，两维分开。**主号唯一**——能发令、能发码、能增删分号、能看全部；**分号只能被控**——没有发令权，只能看到自己名下节点（过滤在控制面做，不在客户端做，否则改个脚本就绕过了）。闸门顺序刻意是**先分权、再仲裁**：分号即使占了领袖位也拒，因为没有权限跟谁是领袖无关；两道闸失败语义也不同（分权是安全、拒绝即拒绝；仲裁是协同、状态文件坏了就放行）。令牌自带角色与过期时间，并带权限版本 `pv`——**吊销分号后旧令牌立刻作废**，不等自然过期。**授权码**（用户要的「密码生成器 / 扫码同步权限」）是**同一枚一次性码的两种呈现**：终端里念 6 位短码，手机上画二维码；6 位用去掉 0/O/1/I 的 32 字母表（≈10 亿组合）+ 5 分钟寿命 + 一次性；二维码载荷 `fleet://grant?p=…` 用账本自带密钥签 HMAC，**伪造载荷在查账本之前就被拒**。与入网码刻意分开：入网码离线验签（装设备时可能没网），授权码必须中心验（改权限不能交给客户端自己认）。**诚实边界**：没有找回密码——主号忘了只能删账本重建（会连带吊销所有分号），因为找回通道本身就是后门。
  - **主动发现（`discovery.py`）**：不问「你是谁」，自己看、自己猜、自己归类。三条路互补——**组播询问**（SSDP M-SEARCH + mDNS 手写 DNS 解析，设备自己举手报名，信息最准）、**邻居表 + OUI**（读 arp/ip neigh，零打扰，靠 MAC 前三字节查厂商）、**特征端口组合**（单端口只能投票，`9000+554+23+8080` 这种**招牌组合**才定案）。实测在真实局域网上认出了具体型号：`HIKVISION DS-2CD2T10FD-I3`（6 台，连序列号都有）、`TPOS/1.0.0 UPnP/1.0 YLWR1200G易展版`（TP-Link 路由）。三条铁律写在代码里：只在本网段活动（跨网段直接拒）、只对 ARP 表里已存在的 IP 敲端口（不做全网段暴力扫描）、**发现 != 入网**（结果只进发现账本，要成为节点仍需在设备上装 agent 并入网）。**踩过的坑**（都是真实误判，已修）：① 9000 端口曾被当成「编队节点」——它同时是 Portainer/海康 SDK 端口，等于把陌生人当自己人；② `192.168.0.255` 广播地址曾被列为设备；③ 一台开 554 的 Windows 电脑曾被判成摄像头，而它的 mDNS 明明写着 `Microsoft-Windows + iVCam`——**设备自报的身份永远压过端口投票**；④ 多网卡机器不显式绑网卡发组播，一个响应都收不到；⑤ 隐私随机 MAC（本地管理位=1）查 OUI 必然为空，不能当「厂商缺失」。
  - **扩散扫描（`sweep.py`）**：把「ARP 表里有的」扩成「整个网段在场的」。上一版只读 ARP，等于只看见**最近跟本机说过话**的设备——这才是「只扫到 30 台」的真因。四条补齐：**ICMP 全段 sweep**（并发 ping 整个 /24，活着的全部进 ARP 表）、**TCP connect 兜底**（IoT 常关 ICMP 却开着端口）、**NetBIOS(NBNS) 名字查询**（Windows 会把机器名报出来）、**mDNS 服务类型枚举**（`_services._dns-sd._udp.local` 让设备自报有哪些服务）。另加两层：**多网段**（本机每张网卡都扫，实测找回被漏掉的移动热点段 `192.168.137.0/24`——手机就在那里）与**环境画像**（摄像头密度、运营商 IPv6 前缀、OUI 批次）。实网 44 台 / 15 秒 / 两个网段。**踩过的坑**：① 本机 `192.168.0.103` 曾被判成「NAS/存储」（因为本机自己开着 139/445）——比漏发现更糟；② 广播地址 `.255` 曾被当成设备；③ 5555 端口曾被判成「手机」，实际那是安卓一体机/中控终端。**边界**：只发 ICMP/TCP/NBNS PTR，不发应用层指令、不试口令；跨网段「跳板扩散」不做——那需要别人机器上的执行权，现在没有也不该去拿。
  - **一键自测门禁**：`run_selftests.py` 串起全部离线自测（**条数以 `docs/_stats.json` 的 `gates_registered` 为准，这里不手填**——手填的数字必然过期，最后变成「README 说绿、实际没跑」）。覆盖 commander / node_agent / install_windows / ui_automation / rules_relay / rule_engine / policies / arbiter / discovery / sweep / accounts / compute_runner / queue_store / persona / recall / enroll / journal / followups / t4 AI后端 / t6 无线ADB / t7 GUI后端 / t8 语音 / t16 skynet桥接 / t25 工具目录 / t31 对比度 / t32 死链 / t33 心跳 / t34 D1 代发 / t35 ssh+mqtt 通道 等。
  - **两条新通道（D4，2026-10-25）**：`fleet/kinds/ssh_shell.py`（`ssh:shell`）与 `fleet/kinds/mqtt_bus.py`（`mqtt:bus`）。ssh 只**真读** `SSH-2.0-` 版本行（端口开着但不是 sshd 判 `is_ssh=False`，不冒充），执行走系统客户端**不收密码**（argv 里的密码等于公开）；mqtt 用 stdlib 手写 3.1.1（不背 paho），**QoS1 必须等到 PUBACK 才算送达**，CONNACK 返回码翻人话。门禁 `eval_t35_channels` **现起真 broker** 验真投递，且「连不上 / 连上了不说话 / 有服务但不让你进」三态必须分开——**报错文案里出现「连上了」就一定是读到过字节**。
- **有连接即入网 · 可达层（2026-11-01）**：天网过去的模型是「**先入网，才有网**」——
  装 agent → 密码入网 → 账本里一条记录 → 然后才有能力。这个模型对内网自建是对的，
  对**世界上其他设备**是错的：一台同事的笔记本、主人手机上现成的 App、一块能连上的
  开发板，全都进不来，不是因为连不上，是因为「没走入网流程」。
  这轮把拓扑改成**两个同心圆**：

  | 圈 | 判据 | 能做什么 | 怎么来的 |
  |---|---|---|---|
  | 内圈 · 编队节点 | 入过网（有 PSK、账本有记录） | 执行命令 / 算力 / 改配置 | `enroll` / `install_windows.py` |
  | 外圈 · 可达对端 | **只要连得上** | 传文件 / 读名片 / 被看见 | 组播发现 / 探测 / 发送成功 |

  - **设备身份 = fingerprint，不是 IP**（照 LocalSend `discovery/store.rs` 的语义，
    那套已被上亿次安装验证过）。同一台手机换了网段、换了协议、走了热点，都还是它；
    拿 IP 当身份的话，手机一换 WiFi 就长出一个新设备，账本里全是鬼影。
  - **一台设备 = 多条通道**，每条各自 `available` / `unreachable`。断一条**设备不消失**
    （锁屏 30 秒 ≠ 掉网），全断才从默认列表隐去、账本仍留；再通自己回来，
    且失败计数清零。排序规则同 LocalSend：**可用优先 → IPv4 优先 → 最近确认优先**。
  - 🔴 **这两个圈之间那道墙，是这轮最重要的东西：可达 ≠ 可执行。**
    外圈设备**不会**被注册成一张 `BaseDevice`，所以它们天然进不了 `reg.call(...)`
    的目标列表 —— 不是靠「记得别调」，是**结构上够不着**。
    局域网里能连上我们的东西包括同事的笔记本、访客的手机、打印机、摄像头；
    如果「连上了」等于「可以在我这边执行命令」，这功能本身就是个洞。
    LocalSend 敢做「连上就互传」，正因为它的协议里**只有传文件**、且文件由对面的人
    自己点接受。我们把线画在同一个位置：**外圈只能做「对面人会自己确认」的事。**

  **三个实测踩出来的坑（都修了，都写进代码注释）**：
  ① **只 bind 一个 `0.0.0.0` 的 socket 只能看一张网卡**。「有连接就有网」的前提是
  承认连接可以有好几条（有线 + 手机热点 + USB 共享），另外几个网段的设备一个都听
  不到，表现是「明明连着却扫出 0 台」。改成**一张网卡一个 socket、各自 bind 各自
  join**（LocalSend 也是每个接口一个 `SendSocket`）。
  ② **发现不是「听广播」**。真实链路是「我 announce → 对端**用 HTTP 向我发 register**」。
  只听 UDP 的话，能听到的只有正好也在广播的设备；安安静静开着等被叫的那些，
  回执全打空。所以扫描期间要临时开一个 TCP 收件口。
  ③ **announce 里报的端口必须真的是我们在听的那个**。报 53317 却绑在别处，
  对端照报的端口回 register，直接 `10061 连接被拒` —— 看着像「对方不响应」，
  其实是自己报错了门牌号。

  **诚实边界**：只做 v2（不做 v1 / 不做 download API）；接收端**只支持 HTTP**
  （在本机起 TLS 要管自签证书，没做就是没做）；客户端侧连 HTTPS 对端**不校验证书**
  —— 这是协议本身的设计（首次信任 + 指纹人工核对，指纹会回写在结果里），不是偷懒。

- **联网层接活 + 取文增强（2026-10-24）**：netforce 采集内核从「README 写着已接、实测全降级」修到真能用——**路径候选制 + marker 判定**（换盘换机不用再指路径，唯一约定 = 两个项目放同一个父目录，判据是 `resource_finder.py` + `skynet/` 子包同时在）；新增 `web.origin` 跳转链穿透与 `web.dns` DoH 污染判据。实测 httpbin 三跳穿透到终点、CDN 站不误报。自测 **73/74**，唯一红的 t8 是本机缺 `polaris-audio-io` 模块（train_15b 整个迁走）——代码现在如实报「缺模块」而不是误报「缺解释器」。

```bash

python run_selftests.py motion storyboard # 按名字子串挑
python run_selftests.py --all            # 全量（发布前跑）
python run_selftests.py --slowest        # 看历史耗时排行，谁在拖后腿
```

**为什么不再每次全量跑**：117 项串起来十几分钟，而改一行 `fleet/motion.py` 跟手机配对、
桌面壳、审批闭环毫无关系。手工给每项贴模块标签是死路（新增一项就漂），所以
`tools/gate_map.py` 从代码里**推**影响面：每个自测项的入口文件做 import 闭包，
得到「这项依赖哪些文件」，再用 `git status/diff` 反查。

关键是**保留依赖距离**：`commander` 的自测并没有 import `fleet/motion.py`，它是经
`commander → node_agent → video_gen_runner → motion` 传过来的；把这种三层传递依赖
也算「受影响」，最慢的那项就会被任何改动拖进来，按改动跑立刻退化成全量。
所以默认只跑**直接依赖（距离 ≤1）**，更远的用 `--deep` 才带上。

实测：改 `fleet/motion.py` → 2 项 13 秒；改视频三件套 → 5 项。碰上
`capabilities.py` / `fleet/catalog.py` 这类被几十项直接依赖的**公共模块**，
工具会明说「影响面是全仓级的」，那时才值得补一次 `--all`。

刻意**不做并发**：这批测试会起本地 HTTP 服务、抢端口（`t48` 端口冲突就是老账），
并行跑出来的红是假的，比慢更糟。

## 作业层 + 产物中心（长任务的地基）

同步调用（`call`）适合「点一下、读一屏」，撑不住手机算力的真实形态——SDXL 实测 **179s/步**、视频生成、4B 长文都是分钟级。所以补了两层：

**作业层（`fleet/jobs.py`）** —— 把「提交」与「执行」拆开：

| 能力 | 说明 |
|---|---|
| `job.submit` | 提交长任务，进盘账本（`~/.fleet/jobs.json`） |
| `job.list` / `job.get` | 按状态筛、查状态历史（每次尝试都有记录） |
| `job.cancel` | 排队中/运行中都能取消；终态作业**如实说不必取消** |

三条硬语义：**① 租约**——节点领走后必须在 180s 内续租或回报，过期即判掉线；**② 掉线迁移**——过期未超次数就退回队列、清空节点，换台机器接着跑；**③ 永久失败不重试**——能力不认识/参数不可能对这类错误一次判死，不浪费别的节点再跑一遍。

REPL：`job submit image.gen {"prompt":"一只蓝鲸"} node=phone1` / `job list failed` / `job show <id>` / `job cancel <id>` / `job reap` / `job pump <节点>`。

**产物中心（`fleet/artifacts.py`）** —— 把文件变成有身份的东西：

- 内容寻址：`art-` + sha256 前 16 位，**同内容不重复存盘**，跨机器只认 id 不认路径；
- 元数据：kind / size / 来源节点 / 关联作业 / TTL；
- `artifact.put`（路径或 base64）/ `artifact.get`（回 base64）/ `artifact.list` / `gc`；
- 取不到时**分清「没这条」和「索引在但文件丢了」**，不冒充成功。

这层解开三个断链：换机引用不到、重复传输、记忆/技能无法指向一个产物。

**对外可见性**（自动，无需改三份清单）：两项都进了注册表与能力说明书，因此终端补全、MCP 工具表、「她」能看见的东西同时生效——只读项（`job.list`/`job.get`/`artifact.get`/`artifact.list`）默认导出给外部 AI 客户端，副作用项（`job.submit`/`job.cancel`/`artifact.put`）只在 `--unsafe` 下导出，且过注册表闸门（无 gate 一律 fail-closed）。

门禁：`evals/test_jobs_artifacts.py`（38 项，含状态机、去重、GC、注册表真表、MCP 导出）。

## 四原则（设计铁律）

1. **锚定最底层 OS 平台层**：只对接 Android / Windows / Linux / Apple 四大平台原生能力，绝不对接厂商 App / 云。米家 leaf（灯/插座/传感器）是 MCU+RTOS 非安卓，经你自控的 Linux/Android 网关桥接；Apple 标「半可达」（仅屏共/快捷指令）。
2. **单一自包含工具箱 + 反向推送**：不要求每台设备各自去公网下载 agent；由手机/家服持一份自包含工具箱（二进制+依赖+配置+幂等安装脚本），接触即推。
3. **病毒式执行模型（同源 RMM/MDM/远控）**：一次进入 → 提权到最高 → 无弹窗 → 常驻后台 → 可远程 → 叠能力。区分合法/恶意只凭三点：归属（是否有权管理）、同意（本人或授权人许可）、范围（只部署在有权限设备、不向他人扩散、不窃他人数据）。
4. **无条件最高权限 + 常驻 + 零运行时分支**：agent 内部不设「能不能推 / 是不是家」之类 if——拿到 admin 即提满、常驻、静默、可远程；**边界靠两道外部闸**（非运行时逻辑，故无 bug）：①管理员启动闸（OS 强制，无 admin 提不上去）②环境复位闸（重装/合规清理自清）。

> **L1 落点**：Windows = SYSTEM 服务 / 计划任务；Linux = systemd root；Android = 已 root 应用 UID。跨重启常驻；重装系统即清——**这是特性不是缺陷**（不被「删不掉」反噬）。L2 内核驱动（抗本机管理员卸）与 L3 固件级均**不做**。

## 联网层（`web.*`）

编队原来只能碰本地设备（手机 / 本机 / 局域网 / 编队节点），**联网是空的**。
联网层把两个外部项目当成「远程设备」接进同一张注册表——它们在注册表里跟手机没有
本质区别：都是「有的能力现在能用，有的现在不能用，问一句才知道」。

| 源 | 位置（**自动发现**，不写死盘符） | 提供 |
|---|---|---|
| netforce | 与本仓并列的 `netforce/`（或 `NETFORCE_HOME` 指定） | 资源站发现 / 游戏 wiki 角色语料 / 站群扩散 / 采集内核 8 层 |
| ai_frontier_crawl | `train_15b/tools`（本机未装，能力如实不可用） | arXiv 12 类 + HF Papers + OpenAlex 中英论文 |

| 能力 | 干什么 | 性质 |
|---|---|---|
| `web.status` | 联网层现状（两个源在不在 / 各攒了多少） | 只读 |
| `web.discover` | 资源站发现（它自己是无限流，**必须限时**） | 动手 |
| `web.corpus` | 游戏 wiki 角色语料 | 动手 |
| `web.diffuse` | 站群扩散盘点（逐个判活） | 动手 |
| `web.papers` | 前沿论文抓取 | 动手 |
| `web.frontier` | 今天的论文清单 | 只读 |
| `web.sites` | 站群活站清单 | 只读 |
| `web.search` | 多引擎聚合搜索（意图校验 + 引擎健康度自动淘汰） | 只读 |
| `web.fetch` | 取一个 URL 的正文（熔断 / 限速 / raw 镜像降级） | 只读 |
| `web.probe` | 判一个页面值不值得抓（四级判定） | 只读 |
| `web.structure` | 探站结构：robots / sitemap / feed | 只读 |
| `web.download` | 下载到本地（真 Range 续传） | 动手 |
| `web.origin` | 跳转链穿透：短链 / 跳板页走到终点（meta refresh / JS location 都算一跳） | 只读 |
| `web.dns` | DNS 污染判据：系统解析 vs DoH 对比（无交集只报可疑，不下结论） | 只读 |

三条不直观的地方：

- **长活走子进程，短活直接 import。** 发现模式一跑就是到次日 6 点 ⇒ 必须子进程
  （import 等于把无限循环塞进我们进程，且没法中途叫停）；采集内核是短任务
  （一次搜索几十秒）⇒ 直接 import 拿结构化结果，比解析 stdout 稳。两条路按性质选。
- **路径候选制 + marker 判定，换机不用再指。** 环境变量仍是最优先逃生口；
  不设则按候选目录找——第一条就是「**与本仓并列的 netforce/**」，
  判据是 `resource_finder.py` + `skynet/` 子包**同时在**。⇒ 换盘、换机、
  换 clone 位置都不用改代码，唯一约定是两个项目放同一个父目录。
  （2026-10-24 修的：原先硬编码 `D:\code\netforce`，在另一台电脑上写的，
  换机后 12 个能力全静默降级成「没装」，而 README 仍写着已接。）
  没装就自动降级：只塌那一组能力，其余照常，且**如实说没装**、不编数据。
- **域是 `web.*` 不是 `net.*`。** 局域网那台扫描器早就占了 `net.scan` / `net.nearby`，
  而能力名必须唯一——重名在注册表里会当场炸。

## 终端：两个显影面，一套命令

设备层的所有能力有两个入口，但**只有一套命令**——加一个能力只改注册表一处，两边同时出现。

```bash
# 全屏（人在电脑前）：双击 fleet-tui.bat，或
python fleet_tui.py
# 命令行（不想进全屏 / 要往管道里塞输出）：双击 fleet-cli.bat，或
python -m fleet.shell

# 不进交互，只跑一条
python -m fleet.shell -c "caps phone"
# 不进交互，把这一屏导出成 SVG（想看它长什么样时）
python -m fleet.tui --shot tmp/shot.svg
# 门禁：headless 跑一遍自检
python -m fleet.tui --smoke
```

全屏那一屏长这样：**左边设备、右边全部能力、中间是发生过的一切**（她的话、事件、每次调用的结果）。键位不用记，底部有一条常驻的键位条。

| 键 | 作用 |
|---|---|
| `ctrl+e` / `ctrl+d` / `ctrl+k` | 光标跳到 命令行 / 设备表 / 能力表 |
| 右表选中后回车 | 把能力名提到命令行（不用手敲，也不用猜它叫什么） |
| `↑` / `↓` | 命令行上下翻历史 |
| `ctrl+y` | 放行破坏性操作（它会先把破坏性命令拦下并报出来，等你按） |
| `ctrl+r` / `ctrl+s` / `ctrl+l` | 重新探测 / 落盘 / 清屏 |
| `f1` / `ctrl+q` | 用法 / 退出 |

**打包**：push 到 `main` 或打 `v*` tag 时，GitHub Actions 用 PyInstaller 构建 `fleet-tui.exe` 并上传为构建产物（tag 还会挂到 release 上）。

两个 bat 都自己找解释器（本机 portable → `py -3` → `python`），且每个候选都要**真跑通一次**才要——Windows 商店那个存根会假装自己是 python（静默 exit=49），不实测就会被它骗到。要用别的解释器：先 `set FLEET_PY=你的python.exe` 再打开。

## 真机部署（Windows）

```bash
# 1) 一台当 Commander（建议走 Tailscale 虚网，不在公网裸奔）
python commander.py --password 你的密码 --host 0.0.0.0 --port 9000

# 2) 另一台装常驻节点（管理员跑一次即永久常驻、无弹窗）
python install_windows.py --install --name PC-B --host <CommanderIP> --port 9000 --password 你的密码

# 2b) 或：扫码入网（推荐，不必在新机器上敲密码）
#     在 Commander 控制台签发 -> 把输出的 fleet:// 文本渲成二维码 -> 目标机扫/粘贴
enroll PC-B                    # 得到 fleet://enroll?p=...（10 分钟、一次性、绑 PC-B）
python install_windows.py --enroll "fleet://enroll?p=..." --dry-run   # 先在目标机验签看参数
python install_windows.py --enroll "fleet://enroll?p=..."             # 兑换并装（管理员）

# 3) 控制台
nodes                      # 看在线节点 + 能力
exec PC-B ipconfig         # 单点执行
broadcast echo 统一指令    # 一条意图扇出所有节点
ctx_put her key 值         # 写共享上下文（跨设备记忆）
compute 帮我写段代码        # 路由到算力节点跑重活（她三段式 ③）
computemap a;b;c          # 批量分发多算力节点聚合
computepool               # 看算力池
ui Her-Phone com.xx.app   # 让节点按规则库当前版本跳广告（--vision 走视觉兜底）
rules / rules_put <文件>  # 规则库：看版本 / 发布会自动带版本下发
rules_rollback 1          # 回滚（生成新版本，历史保留）
policy / policy_eval '{...}'  # 看生效策略 / dry-run 一个事件
arbiter                  # 多控制面仲裁：谁是领袖 / 本机是领袖还是待机
her / her_say 你在干嘛     # 看她的状态 / 让她现在说一句（走频控刹车）
her_memory                # 列出她能回忆的往事（隔日 12h–72h，可人工核对是否真的记得）
her_followups / done <topic>    # 看 24h 没闭环的账 / 告诉系统这事做完了（清账）
journal [n]                     # 回看对话流水（她起话题的依据都在这）
intent 巡检                # 统一意图编排：一句话 -> 多步带依赖 -> 失败逆序回滚
cap / token ...           # 她能力授权 / 配对设备令牌

# 4) 算力接真模型（任一节点设了即可，改环境变量即切换，代码零改动）
set FLEET_LLM_CMD=ollama run qwen3:4b
set FLEET_LLM_URL=http://127.0.0.1:8080
```

> 真部署须收紧 exec 白名单并走 Tailscale；当前白名单仅含演示命令。
>
> 排查通信问题：`FLEET_DEBUG=1` 打开后，收发帧、超时、连接 fd、以及周期线程栈都会打出来——
> 同类「帧已写出但对面没收到」的问题不必再猜。

## 安全与伦理边界

- **只管自己的设备**：部署在你拥有或被明确授权管理的机器上；不向无权/陌生机器推送，不窃取他人数据。
- **不碰恶意线**：不做 UAC 静默绕过（属提权漏洞利用）、不用 BYOVD（借漏洞签名驱动）、不写固件级持久化。
- **可清除**：L1 常驻重装即清；卸载须经密码闸门（`install_windows.py --uninstall --password ...`）。
- **合规兜底**：临时/公共节点（如网吧）采用无状态执行端 + 身份随身（记忆留手机侧），下机即清、不落凭据，与场所合规清理互补。
